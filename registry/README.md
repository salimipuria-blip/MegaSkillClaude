# registry — بانک‌های Infinity Mega Skill

| فایل | محتوا | به‌روزرسانی |
|---|---|---|
| `providers.json` | ارائه‌دهنده‌های LLM رایگان/ارزان، کلید لازم، نقطهٔ قوت، وضعیت بررسی | دستی |
| `agents.json` | ایجنت‌ها، معیارها و وزن هر جایگاه | دستی |
| `models.json` | فهرست زندهٔ مدل‌ها (رایگان، سرعت، قیمت) | `node scripts/registry/refresh_free_models.mjs` |

- کلیدها هرگز اینجا نوشته نمی‌شوند؛ فقط نام متغیر محیطی. تست `tests/test_infinity_registry.py` هر رشتهٔ شبیه کلید را رد می‌کند.
- `verify`: `live` یعنی از sandbox پاسخ گرفته شد، `docs` یعنی از مستندات آمده و هنوز زنده بررسی نشده، `unknown` یعنی نام از مالک آمده و هنوز شناسایی نشده.
- ارائه‌دهندهٔ کلیددار (Groq، Cerebras، Mistral، NVIDIA، SambaNova) فقط وقتی متغیرش تنظیم باشد خوانده می‌شود. نبود کلید در خروجی `skipped` ثبت می‌شود، نه موفق.
