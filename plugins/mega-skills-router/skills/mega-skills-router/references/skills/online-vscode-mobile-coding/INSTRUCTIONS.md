# online-vscode-mobile-coding

## هدف
کاربر بتواند فقط با آیفون (یا هر موبایل) همان کاری را بکند که روی دسکتاپ با VS Code می‌کند: باز کردن و ویرایش فایل‌های این ریپو، استفاده از Claude و همهٔ مهارت‌های مگااسکیل، اجرای تست‌ها و باز کردن PR — بدون نصب هیچ برنامه‌ای و بدون لپ‌تاپ. هر کس هم که به این ریپو دسترسی داشته باشد، همین مهارت را خودکار دارد؛ چون مسیریاب در `.claude/skills/mega-skills-router/` داخل خود ریپوست.

## چه زمانی فعال شود
وقتی کاربر می‌گوید «از آیفون کد بزنم»، «VS Code آنلاین»، «بدون لپ‌تاپ»، «از گوشی ریپو را ویرایش کنم» یا می‌خواهد لینک/روش ورود به محیط کدنویسی موبایل را بگیرد.

## گردش کار
1. **کنسول آیفون را باز کن**: صفحهٔ `mobile/` همین ریپو (وب‌اپ PWA فارسی؛ از Safari با «Add to Home Screen» روی صفحهٔ اصلی آیفون نصب می‌شود). از آنجا جست‌وجوی آفلاین مهارت‌ها، پروژه‌ها و دستورهای تست در دسترس است.
2. **ورود به VS Code آنلاین**: از کنسول دکمهٔ «باز کردن در VS Code» را بزن یا مستقیم برو به `https://vscode.dev/github/salimipuria-blip/MegaSkillClaude` و با همان حساب گیت‌هابی که به ریپو دسترسی دارد وارد شو. جایگزین سبک‌تر: `https://github.dev/salimipuria-blip/MegaSkillClaude` (همان ویرایشگر، با کلید `.`).
3. **رفتن سراغ پروژهٔ درست**: قبل از ویرایش، دستور اختصاصی همان پروژه را در `docs/directives/` بخوان (`00` تا `09`) — مأموریت، فایل‌های کلیدی، دستور تست و پروتکل دیباگ هر پروژه آنجاست. پوشهٔ پروژه را از کنسول مستقیم در VS Code باز کن.
4. **استفاده از مهارت‌ها**: در VS Code افزونهٔ Claude را نصب/فعال کن (`anthropic.claude-code`؛ پیشنهادش در `.vscode/extensions.json` هم هست). مهارت `mega-skills-router` خودکار فعال است؛ کافی است کار را به فارسی بگویی تا مسیریاب از بین ۵٬۷۰۰+ مهارت، مهارت مرتبط را پیدا کند. بیرون از این ریپو: `/plugin marketplace add salimipuria-blip/MegaSkillClaude` و بعد `/plugin install mega-skills-router@psk`.
5. **کدنویسی و تست**: تغییر را کوچک و متمرکز انجام بده و دستور تست همان پروژه را اجرا کن (از تب «عملیات» کنسول کپی می‌شود). خروجی واقعی تست را ببین؛ «انجام شد» بدون خروجی تست ممنوع.
6. **تحویل**: کامیت روی برنچ کاری، Push و ساخت PR برای بازبینی انسانی. **بدون auto-merge و بدون PR اسکلتی**؛ هیچ کلید/توکنی در کد، کامیت یا چت نوشته نشود.

## عیب‌یابی سریع
- **VS Code آنلاین ریپو را نشان نمی‌دهد**: ورود با حساب درست گیت‌هاب و دسترسی به ریپوی خصوصی را بررسی کن؛ صفحه را در Safari (نه مرورگر داخل اپ‌ها) باز کن.
- **مهارت پیدا نمی‌شود**: عبارت را با مترادف فارسی/انگلیسی/فینگلیش دوباره در کنسول یا مسیریاب امتحان کن؛ مسیریاب CLI: `python3 .claude/skills/mega-skills-router/scripts/route.py "<عبارت>"`.
- **تست در موبایل اجرا نمی‌شود**: VS Code وب ترمینال ابری ندارد؛ تست را در محیط ابری/CI اجرا کن (Actions گیت‌هاب) و نتیجه را از تب Actions ببین، یا دستور کپی‌شده را در ترمینال ابری اجرا کن.
- **ایندکس مهارت‌های کنسول قدیمی است**: از ریشهٔ ریپو `python3 mobile/build-index.py` و بعد `--check`؛ فایل `mobile/skills-index.json` را دستی ویرایش نکن.

## چک‌لیست کیفیت
- [ ] پروژه و دستور اختصاصی‌اش در `docs/directives/` خوانده شده
- [ ] تغییر در VS Code آنلاین با حساب و برنچ درست انجام شده
- [ ] دستور تست همان پروژه اجرا و خروجی‌اش دیده شده
- [ ] هیچ راز/توکنی در diff نیست
- [ ] PR برای بازبینی انسانی باز شده و auto-merge نشده

## خروجی
لینک مستقیم VS Code آنلاین همان پروژه/فایل + خلاصهٔ تغییر + خروجی تست + لینک PR. اگر کاربر فقط «می‌خواهم کد بزنم» گفته، اول لینک ورود و مسیر پروژه را بده، بعد سؤال اضافی بپرس.
