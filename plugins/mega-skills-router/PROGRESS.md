# مسیریاب و کتابخانهٔ مهارت‌ها — دفتر جریان پروژه

> توضیح زندهٔ پروژه؛ هر دور کاری همین‌جا اضافه می‌شود. آخرین به‌روزرسانی: **۲۰۲۶-۱۰-۱۴**.

## ۱) پروژه در یک نگاه
- **سه نمای یک چیز:** `.claude/skills/mega-skills-router/` (منبع canonical برای Claude Code)،
  `plugins/mega-skills-router/` (پلاگین قابل‌نصب)، `library/` (کتابخانهٔ مهارت‌های گیت‌هابی)
- **ابزارها:** `scripts/sync_skill_library.py` (هم‌گام‌سازی + `--check`)،
  `scripts/verify_skills.py` (هش SHA-256)، `scripts/repo_health_check.sh`
- **مصرف‌کنندهٔ دیگر:** `mobile/build-index.py` از `triggers.json` همین مسیریاب ایندکس می‌سازد

## ۲) دستور دقیق این پروژه
```bash
python3 scripts/sync_skill_library.py --check   # از ریشه: صفر فایل متفاوت؟
python3 -m unittest discover -s tests -p "test_*.py"
python3 scripts/verify_skills.py --strict       # گزارشی
node scripts/doctor.mjs router                  # هر سه با هم
```

  به `library/github-skills/scripts/*.mjs` ارجاع می‌دهند که در این چک‌اوت نیست — پایین را ببینید) |

## ۴) این دور چه دیده شد
- **یافتهٔ نیازمند پیگیری (نه خطای فعلی):** `library/github-skills/archify/package.json` هشت اسکریپت
  (`test`، `build:*`، `generate:viewer`، `check:release-identity`…) را به
  `library/github-skills/scripts/*.mjs` وصل می‌کند که در این مخزن وجود ندارند. اگر آن پکیج
  هیچ‌وقت اجرا نشود مشکلی نیست، ولی `npm test` داخلش قطعاً شکست می‌خورد. دو راه:
  (الف) اضافه‌کردن آن اسکریپت‌ها، (ب) تبدیل `archify` به «منبع فقط». تا تصمیم، در CI اجرا نمی‌شود.
- هم‌گامی سه‌نمای مهارت‌ها تأیید شد؛ هیچ drift نیست.

## ۶) لاگ جریان (فقط اضافه می‌شود)
- **۲۰۲۶-۱۰-۱۴** — تأیید هم‌گامی (۰ فایل متفاوت)، ۴۹ تست ریشه سبز، شناسایی ارجاع‌های ناقص
  `archify` به‌عنوان بند باز.
- **۲۰۲۶-۱۰-۱۴ (گیت کامل monorepo و اصلاح شمارنده‌ها)** — 56 تست ریشه سبز؛ doctor `router`: sync بدون drift، آزمون‌های Python و verify-skills سبز. ممیزی شمارنده‌ها اختلاف README قدیمی را پیدا کرد: منبع canonical اکنون 6,019 کل / 5,738 routable / 281 incomplete / 30,080 trigger (3,000 core + 8 project + 3,011 GitHub). READMEها، bootstrap metadataهای دو مسیر و regression تست counts هم‌زمان شدند؛ 2,980 فقط snapshot تاریخی 2026-10-04 در README GitHub است.

- **۲۰۲۶-۱۰-۱۴ (دور سراسری — ارجاع‌های شکسته‌ی package.json به گیت تبدیل شد)** — یافته‌ی دستیِ دور قبل (هشت اسکریپتِ `archify` به `library/github-skills/scripts/*.mjs` اشاره می‌کنند که در این مخزن نیست) اکنون خودکار و دائمی بررسی می‌شود.
  - `tests/test_package_scripts.py` (۳ تست) هر `package.json` زیر `library/` و `plugins/` را می‌خواند، آرگومان‌های فایلیِ هر اسکریپت را **نسبت به پوشه‌ی همان پکیج** resolve می‌کند و وجودشان را بررسی می‌کند. اسکنِ اولیه **۱۸ ارجاع شکسته** را نشان داد: ۹ مورد در `library/github-skills/archify` و ۹ موردِ آینه‌ای در `plugins/.../skills/archify`.
  - **تصمیم مستند (نه چشم‌پوشی):** پکیجِ `archify` در یک دیکشنریِ `KNOWN_SOURCE_ONLY` با دلیلِ مکتوب و تاریخ ثبت شد — این مهارت از بالادست به‌صورت «منبع/مرجع» وندور شده و ابزارهای `../scripts/*.mjs`اش جزو این مخزن نیستند، پس `npm test` داخل پکیج اینجا اجراپذیر نیست. ویرایشِ package.jsonِ یک مهارتِ وندورشده، drift از بالادست می‌ساخت؛ ثبتِ استثنا صادقانه‌تر از وصله‌ی پنهان است.
  - یک تستِ دوم جلوی پوسیدنِ استثنا را می‌گیرد: اگر روزی آن ارجاع‌ها درست شوند یا پکیج حذف شود، تست **قرمز** می‌شود تا استثنا حذف یا بازنگری شود. متنِ دلیل هم الزامی است.
  - **دستور تأیید:** `node scripts/doctor.mjs router` → هم‌گامی سه‌نما (۰ فایل متفاوت)، تست‌های پایتون (۵۶ تست ریشه + ۳ تست جدید) و `verify_skills.py --strict` سبز.
  - **محدودیت:** این گیت فقط «فایل وجود دارد» را می‌سنجد، نه «اسکریپت واقعاً کار می‌کند» را؛ اجرای واقعی همچنان به دسترسیِ محیطی نیاز دارد.

- **۲۰۲۶-۱۰-۱۷ (مسیریاب 1.2.0 و بستهٔ Pro)** — سه باگ مسیریاب رفع شد (تطبیق زیررشته‌ای که «ai» را با «maintain» جور می‌کرد، aliasهای چندکلمه‌ای/ZWNJ، خروجی بی‌سقف)؛ وزن‌دهی IDF، اولویت نام مهارت، aliasهای روزمره (سئو، لوگو، کپشن، ریلز، دیباگ…) و fallback خودکار 0.25 اضافه شد. ۱۰ مهارت عمیق `pro-*` (code review، debugging، testing، frontend، backend/API، security، UI design system، UX، brand identity، git) در `library/skills/`؛ شمار: 6,029 کل / 5,748 قابل‌مسیریابی / 281 ناقص / 30,203 trigger. ۷۰ تست ریشه سبز، doctor `router` سبز.

- **۲۰۲۶-۱۰-۱۸ (بریف پروژه، دیباگ مسیریاب، کارایی)** — `CLAUDE.md` پروژه‌ای (دستور کار، yaml spec، قواعد، اشکال‌زدایی، صف کار با معیار پذیرش) ساخته شد و `PROFESSIONAL_GUIDE.md` به ممیزی تاریخ‌دار تبدیل شد.
  - **باگ:** درخواست‌های فارسی پشتهٔ پروژه‌ها به مهارت بی‌ربط می‌رفتند (`تست واحد` → مدل مالی، `ربات تلگرام` → خروجی کانال، `برنامه‌نویسی پایتون` → openpyxl). aliasهای فارسی ابزار/پشته و alias عبارتی چندکلمه‌ای در هر دو `route.py` اضافه شد.
  - **کارایی:** کش ایندکس توکن‌شده در حافظهٔ پروسه (با کلید mtime/size) و fallback تک‌پاس؛ CLI با fallback 2.2s → 0.75s، کل تست‌ها 73.3s → 15.1s.
