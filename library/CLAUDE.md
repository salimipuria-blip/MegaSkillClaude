## نقشهٔ کد
| مسیر | مسئولیت |
|---|---|
| `skills/<name>/SKILL.md` | ۱۸ مهارت خود پروژه؛ نام پوشه = `name` در frontmatter (بررسی‌شده: ۱۸/۱۸) |
| `skills/pro-*` | ۱۰ مهارت حرفه‌ای کدنویسی/طراحی؛ هرمس با `skillByName` از `names.json` آن‌ها را می‌خواند — **تغییر نام = شکستن حالت کدنویسی هرمس** |
| `github-skills/<name>/` | `SKILL.md` بالادستی + `SOURCE.md` (منبع، مجوز، خط `INCOMPLETE:` در صورت نقص) + فایل‌های همراه |
| `github-skills/INDEX.json` | منبع حقیقت شمارش؛ فیلدها: `name, repo, path, license, score, description, url, incomplete` |
| `github-skills/_licenses/` | متن مجوز مخزن‌های مبدأ |
| `install.sh` | نصب ۱۸ مهارت پروژه در `<project>/.claude/skills` یا `~/.claude/skills` |
| `README.md`، `github-skills/README.md` | شمارش‌های اعلام‌شده؛ `tests/test_project_documentation.py` آن‌ها را با `triggers.json` و `INDEX.json` مقایسه می‌کند |

## قواعد سخت (MUST / NEVER)
```text
MUST  edit only library/ (and psk/data/) as source; then run scripts/sync_skill_library.py
MUST  keep folder name == frontmatter `name` for library/skills/* (router + hermes look skills up by name)
MUST  update README counts in the same change whenever skills are added/removed (doc test fails otherwise)
MUST  keep every github skill MIT/permissive with its SOURCE.md and license file
NEVER edit plugins/mega-skills-router/** copies by hand (CI sync --check fails on byte drift)
NEVER execute scripts shipped inside github-skills/* (third-party; generator never runs them either)
NEVER flip `incomplete` without verifying the missing companion files actually exist now
NEVER rename/remove pro-* or prompt-master without updating hermes/coding.mjs and root CLAUDE.md
```

## اشکال‌زدایی
| نشانه | علت محتمل | بررسی | رفع |
|---|---|---|---|
| CI: `sync_skill_library.py --check` قرمز | کپی پلاگین دستی ویرایش شده یا sync اجرا نشده | `python3 scripts/sync_skill_library.py --check` | `python3 scripts/sync_skill_library.py` و commit خروجی |
| `test_router_counts_match…` قرمز | شمارش README با `triggers.json`/`INDEX.json` نمی‌خواند | خواندن `counts` از `triggers.json` | عدد README (انگلیسی با کاما و فارسی) را درست کن |
| هرمس در حالت کدنویسی مهارت Pro را نمی‌آورد | نام پوشهٔ `pro-*` عوض شده یا build-skills اجرا نشده | `ls library/skills`؛ `hermes/public/skills/names.json` | نام را برگردان؛ `npm install` در `hermes` (postinstall) |
| install.sh در پوشهٔ دیگر کار نکند | — (رفع‌شده ۲۰۲۶-۱۰-۱۸: مسیر مطلق و `set -euo pipefail`) | `bash -n library/install.sh` | — |
| لینک نسبی مرده در یک github skill | فایل همراه بالادستی کپی نشده | اسکریپت زیر | یا فایل را از منبع بیاور، یا `incomplete: true` + خط `INCOMPLETE:` و sync |

```bash
# skills whose SKILL.md links to a local file that does not exist (2026-10-18: 114 skills, 67 not flagged incomplete)
python3 - <<'EOF'
import os,re,json
root='library/github-skills'
inc={x['name'] for x in json.load(open(root+'/INDEX.json')) if x['incomplete']}
bad=set()
for d in os.listdir(root):
    p=os.path.join(root,d,'SKILL.md')
    if os.path.exists(p):
        for l in re.findall(r'\]\(([^)#\s]+)\)',open(p,encoding='utf-8',errors='replace').read()):
            if not l.startswith(('http','mailto')) and not os.path.exists(os.path.normpath(os.path.join(root,d,l))): bad.add(d)
print(len(bad), 'unflagged:', sorted(bad-inc))
EOF
```

## صف کار
- **P1 — ۶۷ مهارت GitHub با لینک محلی مرده ولی بدون پرچم `incomplete`.** پذیرش: برای هرکدام یا فایل همراه از مخزن مبدأ اضافه شود، یا پرچم `incomplete` و خط `INCOMPLETE:` بگیرد؛ سپس sync، و شمارش‌ها (`281`) در README پلاگین/کتابخانه/دستور ۰۸ و `tests/test_project_documentation.py` هم‌زمان به‌روز شوند؛ اسکریپت بالا `unflagged: []` بدهد. (برخی لینک‌ها فقط مثال مستند بالادستی‌اند؛ قبل از پرچم‌زدن یکی‌یکی بخوان.)
- **P2 — ۱۰ مهارت `mp-*`** نام frontmatter بدون پیشوند دارند (`code-review`، `research`…) تا با مهارت‌های هم‌نام برخورد نکنند. پذیرش: سیاست نام‌گذاری در `github-skills/README.md` مستند شود یا router برخوردی گزارش نکند (`colliding_triggers: 0` الان برقرار است).
- **P2 — `_licenses/` ‏۴۶ فایل برای ۲۹ مخزن.** پذیرش: یا فایل‌های بی‌مصرف حذف و sync سبز، یا دلیل نگه‌داری در README.

## پروتکل به‌روزرسانی
1. قبل از تغییر: `python3 scripts/sync_skill_library.py --check` و تست‌ها را اجرا کن تا خط مبنا معلوم باشد.
2. فقط منبع (`library/`) را ویرایش کن → `python3 scripts/sync_skill_library.py` → تست‌ها.
3. اگر شمارش‌ها عوض شد: `README.md` هر دو بخش انگلیسی/فارسی، `github-skills/README.md`، README پلاگین و `docs/directives/08-skills-library-router.md`.
4. در `PROFESSIONAL_GUIDE.md` یک ردیف تاریخ‌دار (چه، چرا، نتیجهٔ گیت‌ها) و اینجا بلوک `yaml` و «صف کار» را به‌روز کن.
5. هرگز «انجام شد» بدون خروجی سبز گیت‌ها.
