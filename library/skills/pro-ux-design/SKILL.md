# pro-ux-design

## هدف
کاربر هدفش را با کمترین فکر، قدم و خطا انجام دهد — و کسب‌وکار به نتیجه‌ی قابل‌اندازه‌گیری برسد.

## چه زمانی فعال شود
طراحی صفحه/اپ جدید، checkout یا فرم ثبت‌نام، رابط گیج‌کننده، افت نرخ تبدیل، یا نقد یک طرح.

## گردش کار
1. **کار اصلی کاربر**: «کاربر می‌خواهد ___ تا ___» (job to be done). برای هر نوع کاربر یکی. معیار موفقیت را عددی کن (نرخ تکمیل، زمان، خطا).
2. **جریان کار**: مسیر را از ورود تا موفقیت قدم‌به‌قدم بنویس؛ هر قدم را که می‌شود حذف، خودکار یا ادغام کرد، حذف کن. حالت‌های خطا و بازگشت را هم بکش.
3. **معماری اطلاعات**: منو و دسته‌بندی با واژه‌های خود کاربر (نه اصطلاحات داخلی)؛ حداکثر ۵ تا ۷ گزینه‌ی سطح اول.
4. **Wireframe کم‌جزئیات**: اول چیدمان و اولویت، بعد رنگ. موبایل اول؛ اقدام اصلی در دسترس شست.
5. **فرم‌ها**: فقط فیلدهای ضروری؛ برچسب بالای فیلد؛ اعتبارسنجی هنگام ترک فیلد با پیام راه‌حل‌محور («شماره باید ۱۱ رقم باشد» نه «خطا»)؛ کیبورد مناسب (`inputmode="numeric"` برای موبایل و کد).
6. **ارزیابی هیوریستیک** (نیلسن): وضعیت سیستم معلوم است؟ زبان کاربر؟ کنترل و undo؟ یکدستی؟ پیشگیری از خطا؟ تشخیص به‌جای یادآوری؟ — برای هر مشکل شدت (۰ تا ۴) و راه‌حل بده.
7. **متن رابط**: دکمه = فعل + نتیجه («ثبت سفارش» نه «تأیید»)؛ پیام خالی بودن صفحه راه بعدی را بگوید؛ لحن مطابق برند.
8. **اعتمادسازی (فروشگاه ایرانی)**: نماد اعتماد، شمارهٔ تماس واقعی، شفافیت هزینهٔ ارسال قبل از checkout، روش‌های پرداخت آشنا.
9. **سنجش**: تست کاربردپذیری با ۵ کاربر روی کار اصلی؛ رویدادهای analytics روی هر قدم قیف.

## چک‌لیست کیفیت
- [ ] کار اصلی و معیار موفقیت عددی تعریف شده
- [ ] هر قدم جریان دلیل وجود دارد؛ قدم‌های حذف‌شدنی حذف شده‌اند
- [ ] حالت‌های خطا، خالی و بارگذاری طراحی شده‌اند
- [ ] مسیر اصلی با یک دست روی موبایل قابل‌انجام است
- [ ] یافته‌های هیوریستیک شدت و راه‌حل دارند

## خروجی
بیان کار کاربر + نمودار جریان + wireframe توصیفی صفحات کلیدی + فهرست مشکلات با شدت و راه‌حل + متن‌های رابط + معیارهای سنجش.
