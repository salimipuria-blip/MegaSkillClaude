# VIKING / CINEMATIC MOTION STUDY

این پوشه نمونهٔ حرکتی مستقل وایکینگ با Remotion است؛ ویدئوی نهایی هنوز رندر نشده است و این کد به‌خودی‌خود در نسخهٔ منتشرشدهٔ وب‌اپ نمایش داده نمی‌شود.

## مشخصات
- کامپوزیشن: `VikingCommandIntro`
- نسبت تصویر: ۹:۱۶، ۱۰۸۰×۱۹۲۰، ۳۰ فریم بر ثانیه، ۶ ثانیه
- روش: انیمیشن فریم‌محور با `useCurrentFrame` و `interpolate` و بدون CSS animations؛ حلقهٔ چندلایه، نور نارنجی، ورود تدریجی عنوان و امضای نهایی
- مرجع Figma: https://www.figma.com/design/LJY9KFKYj7LvxaHLG2LFGI

## راه‌اندازی در محیط دارای Node.js

```bash
cd motion
npm install
npm run studio
# برای خروجی فایل MP4 پس از تأیید پیش‌نمایش:
npm run render
```

## نحوهٔ استفادهٔ درست در اپ
رندر ویدیو فقط در ورود اولیه یا معرفی یک سفر استفاده شود؛ در داشبورد اجرایی، ثبت سفر، آپلود و دانلود عکس، فرم‌ها و مسیریابی نباید انیمیشن طولانی جلوی کار را بگیرد. در تنظیمات مرورگر `prefers-reduced-motion`، یک نمای ثابت به‌جای کلیپ پخش شود. پیش از واردکردن MP4 به سایت حجم و سازگاری آیفون بررسی شود.

## محدودیت‌ها
- این فایل‌ها ورود پنج نفر یا فضای عکس مشترک را فراهم نمی‌کنند؛ آن نیازمند احراز هویت، پایگاه‌داده و فضای ذخیره‌سازی مستقل است.
- هیچ آمار سفر/رسانه یا تصویر واقعی جعل نشده است.
