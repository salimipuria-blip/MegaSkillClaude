# V2Ray Hunter — شکار کانفیگ رایگان سریع

کانفیگ‌های رایگان عمومی (vless، vmess، trojan، ss، hysteria2) را از ۶ مخزن جمع‌کنندهٔ معروف می‌گیرد، تکراری‌ها را حذف می‌کند، همه را با هستهٔ واقعی Xray/sing-box (ابزار `xray-knife`) **از اینترنت خودت** تست می‌کند و سریع‌ترین‌ها را برای `v2rayNG` آماده می‌کند.

> پینگ باید از همان شبکه‌ای گرفته شود که از آن وصل می‌شوی. تست از سرور خارج از ایران عدد بی‌معنی می‌دهد؛ برای همین این ابزار را روی گوشی یا کامپیوتر خودت اجرا کن.

## اجرا
- **اندروید (Termux):** `pkg install curl unzip python git` بعد `bash hunt.sh`
- **لینوکس / مک / Git Bash ویندوز:** `bash hunt.sh`

```bash
bash hunt.sh 20 100   # ۲۰ کانفیگ، حداکثر پینگ ۱۰۰ میلی‌ثانیه
```

خروجی در `output/`:
- `best.txt` — لینک‌ها؛ در v2rayNG: ➕ → «Import config from clipboard»
- `best_sub_base64.txt` — همان، به شکل subscription
- `best_report.txt` — جدول پینگ

اگر به اندازهٔ کافی کانفیگ زیر حد پینگ پیدا نشود، سریع‌ترین‌های بعدی را جایگزین می‌کند و پیام می‌دهد.

## نکته‌ها
- منابع در `sources.txt`؛ هر خط یک لینک. اگر `raw.githubusercontent.com` بسته بود، خودکار از آینهٔ `cdn.jsdelivr.net` می‌گیرد.
- کانفیگ‌های رایگان عمومی چند ساعت تا چند روز عمر دارند؛ هر روز دوباره اجرا کن.
- پینگ زیر ۱۰۰ میلی‌ثانیه از ایران معمولاً فقط با سرورهای نزدیک (ترکیه، امارات، ارمنستان، آلمان) یا کانفیگ‌های پشت Cloudflare به دست می‌آید.
- این کانفیگ‌ها مال افراد ناشناس‌اند؛ برای بانک و حساب‌های حساس از آن‌ها استفاده نکن.
