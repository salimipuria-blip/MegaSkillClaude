# نقشهٔ راه هرمس

فهرست کارهای ارتقای هرمس به ترتیب اولویت. روتین روزانهٔ ارتقا هر بار **اولین کار تیک‌نخورده** را برمی‌دارد، می‌سازد، تست می‌کند و یک PR جدا باز می‌کند. هر کار باید رایگان بماند (Cloudflare free + Gemini/Workers AI) و تست داشته باشد.

## انجام‌شده
- [x] بات تلگرام ۲۴/۷ روی Cloudflare Workers، مغز Gemini با پشتیبان Workers AI
- [x] اپ وب به سبک APEX، نصب روی صفحهٔ آیفون
- [x] حساب‌های تیم با نام کاربری/رمز، نقش‌ها و قفل توانایی‌ها
- [x] حافظهٔ دائمی (همهٔ پیام‌ها ذخیره، بایگانی به‌جای پاک کردن) و یادداشت‌های بلندمدت («یادت باشه ...»)
- [x] بستهٔ مهارت‌ها: روش کار + دستورالعمل محتوا، تور، برنامه‌ریزی، ویرایش، ترجمه، پژوهش، کد
- [x] همهٔ ۵٬۹۸۶ مهارت Mega Skills با مسیریاب (تا ۳ مهارت مرتبط برای هر پیام)
- [x] ساخت عکس با «عکس بساز: ...» یا /img در تلگرام و اپ (FLUX.2 و Leonardo و FLUX.1 رایگان روی Workers AI، بدون واترمارک)
- [x] پیام صوتی: ویس تلگرام و دکمهٔ میکروفون اپ (Gemini، پشتیبان Whisper)
- [x] دیدن عکس در تلگرام و اپ (Gemini، پشتیبان LLaVA)
- [x] **استودیوی ویرایش عکس**: بریف بینایی → پیش‌بینی شدت → کاندیدهای چندگانه تا سقف کیفیت → کارنامهٔ امتیاز وزنی با کف هویت و تلاش اصلاحی → تحویل «قبل/بعد»؛ ۱۱ خانوادهٔ ویرایش + کادرهای ۹:۱۶/۱:۱/۴:۵/۱۶:۹، «چند نسخه» (محافظه‌کارانه/متعادل/جسورانه) + **انتخاب نسخه** («نسخهٔ ۲» در تلگرام و دکمهٔ «همین را انتخاب کن» در اپ)، حلقهٔ «ملایم‌تر/قوی‌تر» بدون فرستادن دوبارهٔ عکس، **کیفیت نهایی با upscaler واقعی Stability** (وقتی کلید باشد)، **لایهٔ متن با فونت واقعی** (وزیرمتن: اپ با canvas، تلگرام با Browser Rendering اختیاری، خروجی SVG)، راستی‌آزمایی ابعاد خروجی و گرهٔ Photo Lab در اپ
- [x] جست‌وجوی گوگل برای خبر و قیمت روز، با منبع
- [x] صفحهٔ عمومی سفر و رزرو با تأیید تیم در تلگرام (/trip)
- [x] کانکتورهای گوگل برای مالک: جیمیل (پیش‌نویس)، تقویم، درایو، شیت — با function calling جمینی

## صف کارها
0. [ ] **اینستاگرام از طریق Metricool** (منتظر تصمیم مالک دربارهٔ پلن API متریکول؛ فعلاً متوقف).
1. [ ] **یادآور و خلاصهٔ صبح**: «ساعت ۹ یادم بنداز ...» در تلگرام؛ Cron Trigger هر صبح خلاصهٔ روز و یادآورها را بفرستد. گرهٔ Reminders در اپ آنلاین شود.
2. [x] **پیام صوتی** (انجام شد؛ مانده: جواب صوتی): ویس تلگرام با Workers AI (Whisper) به متن تبدیل و جواب داده شود. گرهٔ Voice آنلاین شود.
3. [x] **دیدن عکس** (انجام شد): عکس در تلگرام و اپ؛ تحلیل و کپشن‌نویسی با مدل بینایی (Gemini یا Workers AI). گرهٔ Vision آنلاین شود.
4. [x] **متن روی عکس** (انجام شد): لایهٔ متن با فونت واقعی وزیرمتن (`textlayer.mjs`) — خواندن واژه/جا/رنگ از جمله، طراحی نسبت به کادر، شکستن خطوط امن، اجرا با canvas در اپ (بالا/وسط/پایین + ذخیرهٔ PNG) و رندر اختیاری سمت سرور با Cloudflare Browser Rendering برای تلگرام، به‌علاوهٔ خروجی SVG.
5. [ ] **فونت دوران**: وقتی فایل فونت رسید، داخل اپ قرار بگیرد و همهٔ متن فارسی با آن نمایش داده شود.
6. [ ] **مدیریت حساب‌ها برای مالک**: ساخت/غیرفعال‌کردن حساب و ریست رمز از داخل اپ (فقط مالک)، بدون نیاز به PR.
7. [ ] **جست‌وجو در بایگانی**: «پارسال درباره‌ی X چی گفتیم؟» از گفتگوهای بایگانی‌شده جواب بدهد.
8. [ ] **تقویم و رزرو تور**: ثبت تورها و رزروها در D1 (رایگان)، یادآوری قبل از حرکت. گرهٔ Calendar آنلاین شود.
9. [ ] **اتصال FJCod**: خواندن داده‌های پروژهٔ FJCod (فقط برای حساب‌هایی که قفل ندارند).
10. [ ] **بات عمومی مشتری وایکینگ**: بات جدا برای سؤال‌های مشتری با جواب‌های تأییدشده و ارجاع به انسان.
11. [ ] **داشبورد مالک**: تعداد پیام‌ها، سهمیهٔ مصرفی Gemini/KV، خطاها.
12. [ ] **مسیریابی بهتر مهارت‌ها**: وزن بیشتر برای تطابق نام مهارت، نمایش مهارت‌های استفاده‌شده در اپ (روشن شدن گره‌ها)، و ارزیابی با چند پرسش نمونهٔ فارسی.

## قانون‌ها برای هر ارتقا
- بدون هزینه، بدون سرور اضافه، بدون کلید جدید مگر لازم و با اجازهٔ مالک.
- هیچ توکن، رمز یا کلیدی در مخزن یا چت نوشته نشود.
- `node --test hermes/worker.test.mjs` باید سبز بماند و برای کار جدید تست اضافه شود.
- بعد از مرج، این فایل به‌روز شود (تیک خوردن کار).
