# نقشهٔ راه هرمس

فهرست کارهای ارتقای هرمس به ترتیب اولویت. روتین روزانهٔ ارتقا هر بار **اولین کار تیک‌نخورده** را برمی‌دارد، می‌سازد، تست می‌کند و یک PR جدا باز می‌کند. هر کار باید رایگان بماند (Cloudflare free + Gemini/Workers AI) و تست داشته باشد.

## انجام‌شده
- [x] بات تلگرام ۲۴/۷ روی Cloudflare Workers، مغز Gemini با پشتیبان Workers AI
- [x] اپ وب به سبک APEX، نصب روی صفحهٔ آیفون
- [x] حساب‌های تیم با نام کاربری/رمز، نقش‌ها و قفل توانایی‌ها
- [x] حافظهٔ دائمی (همهٔ پیام‌ها ذخیره، بایگانی به‌جای پاک کردن) و یادداشت‌های بلندمدت («یادت باشه ...»)
- [x] بستهٔ مهارت‌ها: روش کار + دستورالعمل محتوا، تور، برنامه‌ریزی، ویرایش، ترجمه، پژوهش، کد
- [x] همهٔ ۵٬۹۸۶ مهارت Mega Skills با مسیریاب (تا ۳ مهارت مرتبط برای هر پیام)

- [x] پیام صوتی: ویس تلگرام و دکمهٔ میکروفون اپ (Gemini، پشتیبان Whisper)
- [x] دیدن عکس در تلگرام و اپ (Gemini، پشتیبان LLaVA)
- [x] **استودیوی ویرایش عکس**: بریف بینایی → پیش‌بینی شدت → کاندیدهای چندگانه تا سقف کیفیت → کارنامهٔ امتیاز وزنی با کف هویت و تلاش اصلاحی → تحویل «قبل/بعد»؛ ۱۱ خانوادهٔ ویرایش + کادرهای ۹:۱۶/۱:۱/۴:۵/۱۶:۹، «چند نسخه» (محافظه‌کارانه/متعادل/جسورانه) + **انتخاب نسخه** («نسخهٔ ۲» در تلگرام و دکمهٔ «همین را انتخاب کن» در اپ)، حلقهٔ «ملایم‌تر/قوی‌تر» بدون فرستادن دوبارهٔ عکس، **کیفیت نهایی با upscaler واقعی Stability** (وقتی کلید باشد)، **لایهٔ متن با فونت واقعی** (وزیرمتن: اپ با canvas، تلگرام با Browser Rendering اختیاری، خروجی SVG) و **ویرایش همان لایه با پیام** («بالاتر ببر»، «سفیدش کن»، «بدون نوار»، «متن رو عوض کن…»، «متن رو بردار»)، راستی‌آزمایی ابعاد خروجی و گرهٔ Photo Lab در اپ
- [x] جست‌وجوی گوگل برای خبر و قیمت روز، با منبع
- [x] صفحهٔ عمومی سفر و رزرو با تأیید تیم در تلگرام (/trip)
- [x] **حالت کدنویسی حرفه‌ای**: تشخیص خودکار سؤال کد → دستورالعمل مهندس ارشد (کد کامل و قابل‌اجرا، تست، دستور اجرا، امنیت) + مهارت Pro مرتبط (دیباگ، ریویو، تست، امنیت، API، فرانت، Git) + مدل‌های تخصصی کد هر سرویس و Workers AI + کد بلند به‌صورت فایل در تلگرام؛ برای مالک `/ci`، `/prs`، `/file مسیر`، `/review مسیر` روی ریپو (نیازمند secret اختیاری `GITHUB_REPO_TOKEN`، فقط‌خواندنی) — `coding.mjs`، `github.mjs` + ۱۱ تست.
- [x] **دانش همهٔ پروژه‌ها برای مالک**: `docs/PORTFOLIO.md` + ROADMAP/PROGRESS هر پروژه موقع استقرار در `public/knowledge` می‌نشیند؛ هر سؤال مالک دربارهٔ پروژه‌ها/ریپوها/کار مانده با همان مستندات جواب داده می‌شود و `/projects` نقشهٔ کامل را می‌فرستد (`knowledge.mjs` + ۶ تست). اعضای تیم و مشتری‌ها هرگز آن را نمی‌بینند.
- [x] کانکتورهای گوگل برای مالک: جیمیل (پیش‌نویس)، تقویم، درایو، شیت — با function calling جمینی

## قانون‌ها برای هر ارتقا
- بدون هزینه، بدون سرور اضافه، بدون کلید جدید مگر لازم و با اجازهٔ مالک.
- هیچ توکن، رمز یا کلیدی در مخزن یا چت نوشته نشود.
- `node --test hermes/worker.test.mjs` باید سبز بماند و برای کار جدید تست اضافه شود.
- بعد از مرج، این فایل به‌روز شود (تیک خوردن کار).
