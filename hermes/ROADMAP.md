# نقشهٔ راه هرمس

فهرست کارهای ارتقای هرمس به ترتیب اولویت. روتین روزانهٔ ارتقا هر بار **اولین کار تیک‌نخورده** را برمی‌دارد، می‌سازد، تست می‌کند و یک PR جدا باز می‌کند. هر کار باید رایگان بماند (Cloudflare free + Gemini/Workers AI) و تست داشته باشد.

## انجام‌شده
- [x] بات تلگرام ۲۴/۷ روی Cloudflare Workers، مغز Gemini با پشتیبان Workers AI
- [x] اپ وب به سبک APEX، نصب روی صفحهٔ آیفون
- [x] حساب‌های تیم با نام کاربری/رمز، نقش‌ها و قفل توانایی‌ها
- [x] حافظهٔ دائمی (همهٔ پیام‌ها ذخیره، بایگانی به‌جای پاک کردن) و یادداشت‌های بلندمدت («یادت باشه ...»)
- [x] بستهٔ مهارت‌ها: روش کار + دستورالعمل محتوا، تور، برنامه‌ریزی، ویرایش، ترجمه، پژوهش، کد
- [x] همهٔ ۵٬۹۸۶ مهارت Mega Skills با مسیریاب (تا ۳ مهارت مرتبط برای هر پیام)

## صف کارها
1. [ ] **یادآور و خلاصهٔ صبح**: «ساعت ۹ یادم بنداز ...» در تلگرام؛ Cron Trigger هر صبح خلاصهٔ روز و یادآورها را بفرستد. گرهٔ Reminders در اپ آنلاین شود.
2. [ ] **پیام صوتی**: ویس تلگرام با Workers AI (Whisper) به متن تبدیل و جواب داده شود. گرهٔ Voice آنلاین شود.
3. [ ] **دیدن عکس**: عکس در تلگرام و اپ؛ تحلیل و کپشن‌نویسی با مدل بینایی (Gemini یا Workers AI). گرهٔ Vision آنلاین شود.
4. [ ] **فونت دوران**: وقتی فایل فونت رسید، داخل اپ قرار بگیرد و همهٔ متن فارسی با آن نمایش داده شود.
5. [ ] **مدیریت حساب‌ها برای مالک**: ساخت/غیرفعال‌کردن حساب و ریست رمز از داخل اپ (فقط مالک)، بدون نیاز به PR.
6. [ ] **جست‌وجو در بایگانی**: «پارسال درباره‌ی X چی گفتیم؟» از گفتگوهای بایگانی‌شده جواب بدهد.
7. [ ] **تقویم و رزرو تور**: ثبت تورها و رزروها در D1 (رایگان)، یادآوری قبل از حرکت. گرهٔ Calendar آنلاین شود.
8. [ ] **اتصال FJCod**: خواندن داده‌های پروژهٔ FJCod (فقط برای حساب‌هایی که قفل ندارند).
9. [ ] **بات عمومی مشتری وایکینگ**: بات جدا برای سؤال‌های مشتری با جواب‌های تأییدشده و ارجاع به انسان.
10. [ ] **داشبورد مالک**: تعداد پیام‌ها، سهمیهٔ مصرفی Gemini/KV، خطاها.
11. [ ] **مسیریابی بهتر مهارت‌ها**: وزن بیشتر برای تطابق نام مهارت، نمایش مهارت‌های استفاده‌شده در اپ (روشن شدن گره‌ها)، و ارزیابی با چند پرسش نمونهٔ فارسی.

## قانون‌ها برای هر ارتقا
- بدون هزینه، بدون سرور اضافه، بدون کلید جدید مگر لازم و با اجازهٔ مالک.
- هیچ توکن، رمز یا کلیدی در مخزن یا چت نوشته نشود.
- `node --test hermes/worker.test.mjs` باید سبز بماند و برای کار جدید تست اضافه شود.
- بعد از مرج، این فایل به‌روز شود (تیک خوردن کار).
