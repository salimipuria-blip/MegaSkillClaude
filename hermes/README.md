# هرمس: دستیار ۲۴/۷ در تلگرام

هزینه: ۰. دو نسخه دارد:

| | **هرمس لایت** (پیشنهادی) | هرمس کامل |
|---|---|---|
| کجا اجرا می‌شود | Cloudflare Workers | سرور Oracle Always Free |
| کارت بانکی خارجی | لازم نیست | لازم است (اوراکل ایران را نمی‌پذیرد) |
| سرور یا دستگاه روشن | لازم نیست | سرور اوراکل |
| چه می‌کند | چت با جمینی، حافظهٔ ۲۰ پیام آخر، فقط برای تو | ایجنت کامل هرمس با ابزار و اجرای دستور روی سرور |
| فایل‌ها | `worker.mjs`، `wrangler.toml` | `setup.sh` |

## هرمس لایت روی Cloudflare

فضای حافظه (`hermes-memory`) از قبل در حساب Cloudflare ساخته شده و در `wrangler.toml` وصل است.

**۱. سه چیز آماده کن** (جایی ننویس و برای کسی نفرست)
- **کلید جمینی:** aistudio.google.com ← Get API key. با VPN.
- **توکن بات:** از `@BotFather` ← `/newbot`. اگر بات داری، `/token`.
- **شناسهٔ عددی تلگرام:** به `@userinfobot` پیام `/start` بده.

> **کلید جمینی اختیاری است.** اگر نباشد یا گوگل آن را رد کند (مثلاً 403)، بات خودکار از هوش مصنوعی رایگان خود Cloudflare (Workers AI) استفاده می‌کند. نه کلید می‌خواهد و نه VPN.

**۲. ساخت Worker از همین مخزن**
dash.cloudflare.com ← Workers & Pages ← Create ← **Import a repository** ← GitHub ← `MegaSkillClaude`
- Project name: `hermes` (دقیقاً همین)
- Root directory: `hermes`
- Deploy command: `npx wrangler deploy` (پیش‌فرض)
- ← Deploy

از این به بعد هر تغییری که در پوشهٔ `hermes/` روی `main` برود، خودکار منتشر می‌شود.

**۳. رمزها**
Worker `hermes` ← Settings ← Variables and Secrets ← Add. هر سه را با نوع **Secret** اضافه کن:

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن BotFather |
| `GEMINI_API_KEY` | کلید جمینی |
| `GITHUB_MODELS_TOKEN` | (اختیاری، رایگان) توکن گیت‌هاب با دسترسی Models — مغز پشتیبان GPT-4.1 |
| `GROQ_API_KEY` | (اختیاری، رایگان) کلید console.groq.com — مغز پشتیبان سریع |
| `CEREBRAS_API_KEY` / `OPENROUTER_API_KEY` | (اختیاری، رایگان) مغزهای پشتیبان بیشتر |
| `ALLOWED_USER_ID` | شناسهٔ عددی تو |

> اگر رمزها را اشتباهی در Settings ← Build ← Variables and secrets گذاشتی، مشکلی نیست: `sync-secrets.mjs` موقع هر ساخت آن‌ها را به رمزهای خود بات کپی می‌کند.

**۴. فعال‌سازی:** یک‌بار صفحهٔ اصلی Worker (`https://hermes.<زیردامنهٔ تو>.workers.dev`) را باز یا رفرش کن؛ خودش بات را وصل می‌کند. (`/setup` هم همان کار را می‌کند) (با VPN، چون workers.dev در ایران فیلتر است). باید ببینی:
```
✓ Webhook set for @نام_بات
✓ Memory: on
```

**۵. تست:** در تلگرام به بات بنویس «سلام، خودت را معرفی کن».

### اپ چت (مثل ChatGPT)
در تلگرام به بات بنویس `/app`؛ یک لینک خصوصی می‌دهد. در سافاری بازش کن و **Share ← Add to Home Screen** را بزن تا مثل اپ روی صفحهٔ اصلی بیاید. حافظهٔ اپ با چت تلگرام یکی است. لینک را برای کسی نفرست؛ هر کس آن را داشته باشد می‌تواند با هرمس حرف بزند.

ظاهر اپ: مثل APEX-UI. هستهٔ ذره‌ای داخل حلقهٔ طلایی وسط یک شبکهٔ مدار است. هر گره یکی از توانایی‌های هرمس است؛ آبی یعنی فعال، طلایی یعنی مهارت، خاکستری یعنی در راه. روی هر گره بزنی کارتش باز می‌شود و نمونه‌پیام‌هایش را می‌شود همان‌جا فرستاد. موقع فکر کردن، گره‌هایی که به کار می‌آیند روشن می‌شوند. بالا-چپ ساعت و هوا، بالا-راست تاریخچهٔ گفتگو. طراحی از APEX-UI (مجوز MIT، Ruben Mouradian) الهام گرفته و همه‌اش در `app.mjs` از نو نوشته شده.

### حافظه و مهارت‌ها
- **همهٔ پیام‌ها برای همیشه ذخیره می‌مانند.** هرمس برای جواب، ۴۰ پیام آخر را می‌بیند. «گفتگوی جدید» یا `/reset` گفتگو را بایگانی می‌کند، پاک نمی‌کند.
- **یادداشت بلندمدت:** بنویس «یادت باشه ...» یا «remember that ...». همیشه در نظرش می‌ماند. `/notes` فهرست، `/forget` پاک کردن. در اپ: تاریخچه ← LONG-TERM MEMORY.
- **ویس:** در تلگرام ویس بفرست؛ در اپ دکمهٔ میکروفون را بزن، حرف بزن، دوباره بزن. اول متن ویس را نشان می‌دهد، بعد جواب می‌دهد (Gemini، پشتیبان Whisper روی Workers AI).
- **عکس:** در تلگرام عکس (با یا بی کپشن) بفرست؛ در اپ دکمهٔ دوربین. هرمس عکس را می‌بیند و جواب می‌دهد (Gemini، پشتیبان LLaVA).
- **جست‌وجوی گوگل:** برای خبر، قیمت و چیزهای روز خودش در گوگل می‌گردد و منبع می‌آورد.
- **ساخت عکس:** بنویس «عکس بساز: ...» (یا `/img ...`). بهترین مدل‌های رایگان کلادفلر به ترتیب کیفیت: FLUX.2 [dev] ← Leonardo Lucid Origin ← Leonardo Phoenix ← FLUX.2 [klein] ← FLUX.1 schnell؛ همه بدون واترمارک و از سهمیهٔ رایگان روزانهٔ Workers AI. اندازه از متن: «استوری» ۹:۱۶، «پست» ۴:۵، «بنر» ۱۶:۹. Gemini image فقط اگر حساب گوگل پولی باشد. اگر سهمیهٔ کلادفلر تمام شده باشد، عکس از سرویس رایگان و بدون کلید Pollinations (FLUX) ساخته می‌شود (با `FREE_IMAGES=off` خاموش می‌شود).
- **گوگل (فقط مالک):** جیمیل (خواندن و پیش‌نویس؛ هرگز خودش نمی‌فرستد)، تقویم (دیدن و ساختن رویداد)، درایو (جست‌وجو) و شیت (خواندن و اضافه کردن ردیف). مثلاً «ایمیل‌های خوانده‌نشدهٔ امروز رو خلاصه کن»، «فردا ساعت ۱۰ جلسه با حسام بذار»، «این رزرو رو به شیت رزروها اضافه کن».

- **صفحهٔ سفر و رزرو (عمومی):** `https://<worker>.workers.dev/trip` — لینک بیو. در تلگرام `/trip` لینک را می‌دهد. مسافر فرم را پر می‌کند ← مشخصات رزرو (نام، شماره، تعداد، خودرو، توضیح) به‌صورت پیام خصوصی فقط برای مالک (صاحب شمارهٔ رزرو) در تلگرام فرستاده می‌شود. اطلاعات پرداختی از اینجا ارسال نمی‌شود؛ تیم خودش با مسافر تماس می‌گیرد. بعد از پرداخت کنسلی ندارد.
  - **مسئول رزرو (فقط یک نفر):** صاحب شمارهٔ رزرو (`BOOKING_PHONE`؛ پیش‌فرض داخل کد فقط به‌صورت هش ذخیره شده) یک بار به بات پیام می‌دهد و دکمهٔ «📱 ارسال شمارهٔ من» را می‌زند. اگر شماره خودش باشد و بخواند، از آن به بعد گزارش رزروها فقط برای همان حساب می‌رود و به مالک خبر داده می‌شود. تا قبل از ثبت، گزارش فقط برای مالک می‌رود (شماره مال خود مالک است).
  - `BOOKING_ADMIN_IDS` (اختیاری): آیدی عددی تلگرام بقیهٔ اعضای تیم، با کاما. هر نفر باید یک بار به بات پیام بدهد (بات آیدی‌اش را جواب می‌دهد) — تلگرام با شمارهٔ تلفن پیام نمی‌فرستد.
  - اطلاعات سفر (عنوان، تاریخ، قیمت) در `hermes/booking.mjs` (ثابت `TRIP` و متن صفحه) است.

### اتصال گوگل (یک بار)
1. console.cloud.google.com → پروژهٔ جدید «Hermes».
2. APIs & Services → Library: این‌ها را Enable کن: Gmail API، Google Calendar API، Google Drive API، Google Sheets API.
3. Google Auth Platform → Branding (نام Hermes و ایمیل) → Audience: External و **Publish app** (وگرنه اتصال هر ۷ روز قطع می‌شود؛ هشدار «unverified» برای استفادهٔ شخصی عادی است).
4. Clients → Create client → Web application → Authorized redirect URI: `https://<worker>.workers.dev/connect/google/callback`
5. Client ID و Client secret را در کلادفلر (Workers → hermes → Settings → Variables and Secrets، نوع Secret) با نام‌های `GOOGLE_CLIENT_ID` و `GOOGLE_CLIENT_SECRET` بگذار. در چت نفرست.
6. در تلگرام `/google` را بزن، لینک یک‌بار مصرف را باز کن و اجازه بده. قطع: `/google_off`.
- **مهارت‌ها:** روش کار و دستورالعمل‌های محتوا، تور، برنامه‌ریزی، ویرایش، ترجمه، پژوهش و کد در `skills.mjs` است.
- **کتابخانهٔ کامل مهارت‌ها (Mega Skills):** همهٔ ۵٬۹۸۶ مهارت مخزن (`plugins/mega-skills-router`) موقع دیپلوی با `build-skills.mjs` به فایل‌های داخلی Worker تبدیل می‌شوند. برای هر پیام، `skill-router.mjs` تا ۳ مهارت مرتبط را پیدا می‌کند و دستورالعملشان را به هرمس می‌دهد. پیام‌های معمولی مثل «سلام» بدون مهارت جواب داده می‌شوند.
- **ارتقا:** کارهای بعدی در [`ROADMAP.md`](ROADMAP.md). یک روتین روزانه (۹:۵۵ صبح تهران) اولین کار باز را می‌سازد و PR می‌دهد.

### حساب‌های تیم
اپ برای هم‌تیمی‌ها با نام کاربری و رمز باز می‌شود. هر نفر حافظهٔ گفتگوی جداگانهٔ خودش را دارد. مالک همچنان با لینک `/app` تلگرام وارد می‌شود و حافظه‌اش با تلگرام یکی است.

| نقش | دسترسی |
|---|---|
| مالک | همه‌چیز، با لینک تلگرام |
| ADMIN | همهٔ ابزارهای هوش مصنوعی، دیدن فهرست تیم، تغییر رمز خودش؛ تغییر ساختار ندارد |
| VIKING (عضو) | همهٔ ابزارهای هوش مصنوعی، حافظهٔ شخصی، تغییر رمز خودش |

**قفل‌ها:** هر حساب می‌تواند `locks` داشته باشد. هرمس درخواست دربارهٔ موضوع قفل‌شده را قبل از فرستادن به هوش مصنوعی رد می‌کند و گره‌اش در اپ با 🔒 قرمز دیده می‌شود. فعلاً:
- پوریا: «وایکینگ» قفل، FJCod باز
- بقیه: FJCod قفل، وایکینگ باز
- مالک: همه‌چیز باز

حساب‌ها در `users.mjs` هستند. آنجا فقط هش رمزها ذخیره می‌شود (PBKDF2، ۱۰۰ هزار دور)، نه خود رمز. افزودن نفر جدید:
```bash
node hermes/add-user.mjs <username> "<نام>" member
```
رمز را یک بار چاپ می‌کند (خصوصی بده). خطی که چاپ می‌کند را در `users.mjs` بگذار و مرج کن. بعد از ۸ رمز اشتباه، ورود آن نام کاربری ۱۵ دقیقه بسته می‌شود.

### دستورها در تلگرام
- `/start`: خوش‌آمد
- `/reset`: پاک کردن حافظهٔ گفتگو
- `/app`: لینک خصوصی اپ چت

### اگر گیر کردی

| پیام | راه حل |
|---|---|
| `✗ Missing secrets: ...` | همان رمزها را در قدم ۳ اضافه کن، بعد `/setup` را دوباره باز کن |
| `✗ Telegram rejected ...` | توکن را دوباره از BotFather کپی کن |
| بات می‌گوید «این بات خصوصی است» | عددی که بات نشان داده را در `ALLOWED_USER_ID` بگذار |
| «جمینی کلید را نپذیرفت» | کلید تازه در AI Studio بساز و Secret را عوض کن |
| «سهمیهٔ رایگان جمینی پر است» | محدودیت رایگان گوگل است؛ چند دقیقه صبر کن |
| بات هیچ جوابی نمی‌دهد | `/setup` را دوباره باز کن. اگر درست نشد: Worker ← Logs، اسکرین‌شات بفرست |

### محدودیت‌های رایگان
- Cloudflare: روزی ۱۰۰٬۰۰۰ درخواست.
- حافظه: روزی ۱٬۰۰۰ نوشتن، یعنی حدود ۱٬۰۰۰ پیام در روز.
- جمینی: سهمیهٔ رایگان AI Studio.

تست‌ها: `node --test hermes/worker.test.mjs`

## هرمس کامل روی Oracle (فقط با کارت خارجی واقعی)

اوراکل برای ساخت حساب کلاد کارت ویزا یا مستر به نام خودت و آدرس خارج از ایران می‌خواهد. با اطلاعات جعلی ثبت‌نام نکن، چون حساب و سرور بسته می‌شوند.

**A. ساخت سرور** (کنسول اوراکل)
- مسیر: Compute ← Instances ← Create instance
- Image: Ubuntu 24.04 (aarch64)
- Shape: `VM.Standard.A1.Flex` با ۴ OCPU و ۲۴ گیگابایت رم. برچسب **Always Free** باید دیده شود.
- SSH keys: Generate a key pair for me، بعد **Save private key**
- اگر Out of capacity گرفتی: ۲ OCPU و ۱۲ گیگابایت.

**B. اتصال** با Termius: Host = آی‌پی عمومی، User = `ubuntu`، Key = کلید خصوصی

**C. نصب** (یک خط)
```bash
curl -fsSL https://raw.githubusercontent.com/salimipuria-blip/MegaSkillClaude/main/hermes/setup.sh -o setup.sh && bash setup.sh
```
اسکریپت کلید جمینی، توکن بات و شناسهٔ عددی را می‌پرسد. کلید و توکن موقع تایپ دیده نمی‌شوند و فقط روی همان سرور ذخیره می‌شوند. هرمس به صورت سرویس systemd اجرا می‌شود و بعد از ری‌استارت هم بالا می‌آید.

**نگهداری:** `hermes gateway status`، `hermes gateway restart`، `hermes doctor`. اگر بات ساکت ماند: `journalctl --user -u hermes-gateway -n 50 --no-pager`.


**ترتیب مغزها:** جمینی (همهٔ مدل‌ها) ← GitHub Models ← Groq ← Cerebras ← OpenRouter ← Workers AI. هر کدام که کلیدش نباشد رد می‌شود؛ پر شدن سهمیهٔ یکی، نوبت را به بعدی می‌دهد. نام مدل‌ها را می‌شود با `GITHUB_MODELS`، `GROQ_MODELS` و … (جداشده با کاما) عوض کرد.
