# BISON Brand Book — دفتر جریان پروژه

> توضیح زندهٔ پروژه؛ هر دور کاری همین‌جا اضافه می‌شود. آخرین به‌روزرسانی: **۲۰۲۶-۱۰-۱۴**.

## ۱) پروژه در یک نگاه
- **پوشه:** `bison-brand-book/` · **فناوری:** Vite 6 + GSAP + Lenis (اسکرول سینمایی)
- **انتشار:** Vercel `bison.brandbook.site.2026` و GitHub Pages (هنوز از مخزن قدیمی — بند P0)
- **دارایی سنگین:** `public/BISON-Brand-Book.zip` (۴٫۲MB، در Git نگه داشته می‌شود چون از سایت دانلود می‌شود)

## ۲) دستور دقیق این پروژه
```bash
node scripts/doctor.mjs bison-brand-book   # بیلد + audit
```
معادل دستی:
```bash
cd bison-brand-book
npm ci
npm run build          # vite build → dist/
npm audit --omit=dev   # باید صفر آسیب‌پذیری باشد
npm run dev            # پیش‌نمایش محلی روی 0.0.0.0:5173
```

## ۳) وضعیت تأییدشده (۲۰۲۶-۱۰-۱۴)
| بررسی | نتیجه |
|---|---|
| `npm run build` | ✅ ۱۰ ماژول، `index.html` ۲۳٫۶۲kB، JS ۱۳۹٫۶۷kB (gzip ۵۲٫۵۹kB) |
| `npm audit` (کل درخت) | ✅ **صفر آسیب‌پذیری** — بند P2 نقشهٔ راه (`source-map-js`) دیگر مصداق ندارد |
| ارجاع‌های دارایی در HTML | ✅ `/images/*`, `/favicon.svg`, `/BISON-Brand-Book.zip` همه از `public/` سرو می‌شوند (مسیرهای root-absolute، قرارداد Vite) |

## ۴) دیباگ این دور
- بازبینی: هیچ باگ منطقی یا خطای بیلدی پیدا نشد؛ بیلد و audit هر دو سبز.
- **تناقض مستندات رفع شد:** نقشهٔ راه یک کار P2 («`npm audit fix` برای `source-map-js`») داشت؛
  اجرای واقعی `npm audit` روی درخت فعلی صفر آسیب‌پذیری نشان می‌دهد. این آیتم باید از فهرست باز حذف شود.

## ۶) لاگ جریان (فقط اضافه می‌شود)
- **۲۰۲۶-۱۰-۱۴** — بیلد و audit اجرا و سبز شد؛ آیتم P2 مربوط به `source-map-js` منقضی تشخیص داده شد.
- **۲۰۲۶-۱۰-۱۴ (گیت کامل monorepo)** — نصب تمیز `npm ci`، build و `npm audit --omit=dev` سبز؛ audit درخت runtime صفر آسیب‌پذیری گزارش کرد.

- **۲۰۲۶-۱۰-۱۴ (دور سراسری — اولین قرارداد ایستا + اصلاح ارجاع نسبی)** — این پروژه فقط «بیلد + audit» داشت؛ یعنی یک مسیرِ داراییِ غلط، یک لنگرِ مرده یا حذفِ فایلِ ZIP تا وقتی سایت بالا بود دیده نمی‌شد.
  - **باگ واقعی پیدا و اصلاح شد:** در `index.html:48` لینکِ دانلود به‌صورت **نسبی** (`href="BISON-Brand-Book.zip"`) بود در حالی که بقیهٔ دارایی‌ها قراردادِ root-absolute دارند (`/favicon.svg`, `/images/*`) و `public/download.html` هم از `/BISON-Brand-Book.zip` استفاده می‌کند. مسیرِ نسبی در ریشه درست کار می‌کند اما با هر سرو از زیرمسیر می‌شکند. به `/BISON-Brand-Book.zip` اصلاح شد.
  - `bison-brand-book/tests/static.test.mjs` (۸ تست) + اسکریپت `npm test` اضافه شد: همهٔ ارجاع‌های محلی باید root-absolute باشند؛ هر ارجاعِ `/...` باید در `public/` وجود داشته باشد؛ ZIP موجود و واقعاً ZIP باشد (امضای `PK`)؛ هر لنگر به یک `id` برسد (۱۰ لنگر بررسی شد، قبلاً هیچ‌کدام تست نمی‌شدند)؛ entry pointها وصل باشند؛ هیچ کلید سرویس در فرانت‌اند نباشد؛ `prefers-reduced-motion` هم در CSS و هم در JS (GSAP/Lenis بدون این گارد صفحه را برای کاربرِ حساس به حرکت غیرقابل‌استفاده می‌کند)؛ و پوشه‌های `public/images` و `public/logos` موجود باشند.
  - **اعتبارسنجی با جهش:** برگرداندنِ همان ارجاع نسبی در یک کپیِ موقت، دقیقاً تستِ «root-absolute» را قرمز کرد.
  - به CI (`npm test` پیش از build) و به `scripts/doctor.mjs` (گام `contract`) وصل شد. بیلد بدون تغییر ماند: `index.html` ۲۳٫۶۲kB، JS ۱۳۹٫۶۷kB (gzip ۵۲٫۵۹kB)؛ `npm audit --omit=dev` صفر.
  - **محدودیت:** بازبینیِ بصریِ طراحی (رنگ/تایپوگرافی/انیمیشن) همچنان انجام نشده؛ این گیت فقط ساختار و قراردادها را نگه می‌دارد. بند P0 (اتصال Vercel به همین مخزن) همچنان باز است.
