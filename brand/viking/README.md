# قالب ثابت محتوای وایکینگ آفرود

این قالبِ تأییدشدهٔ مالک برای **همهٔ** پست‌ها و استوری‌های وایکینگ است. محتوای جدید فقط متن و عکسش عوض می‌شود؛ سبک ثابت می‌ماند.

| فایل | خروجی |
|---|---|
| `post.html` | پست اسلایدی ۳ صفحه، ۱۰۸۰×۱۳۵۰ (۴:۵) |
| `story.html` | استوری ۱۰۸۰×۱۹۲۰ (۹:۱۶) |
| `render.mjs` | ساخت PNG: `node brand/viking/render.mjs post` یا `story` |

## قواعد سبک (ثابت)

- **عکس:** سینمایی و زنده؛ طلوع/غروب، مه، نور گرم، آب یا جنگل؛ سوژه (آدم/جیپ/پدل) کوچک وسط کادر و دیده‌شدنی. هیچ‌وقت عکس بی‌روح یا روز صاف. اشباع کمی بالا (`saturate(1.25)`) + هالهٔ خورشید نارنجی.
- **رنگ‌ها:** نارنجی برند `#F39A2B`، مشکی `#141414`، کرم `#FFD9A8`، قرمز هشدار `#FF4D3D` (فقط برای خط‌خوردگی/جایزه)، سفید.
- **فونت:** تیتر Lalezar (درشت، نارنجی با درخشش)، متن Vazirmatn (Black/Bold/Medium).
- **نوار کج (tape):** بالا نارنجی با پیام اصلی (🔥 …)، پایین سفید با CTA. زاویهٔ ۲.۵ تا ۴ درجه.
- **لوگو:** دایره‌ای، گوشهٔ بالا راست، با سایه.
- **هیجان/FOMO فقط با واقعیت:** ددلاین واقعی، ظرفیت واقعی، قیمت واقعی خط‌خورده. ادعای ساختگی (کمبود جعلی، «هر چی زودتر شانست بیشتر» در قرعه‌کشی) ممنوع.
- **کارت‌ها:** پس‌زمینهٔ تیرهٔ نیمه‌شفاف، حاشیهٔ نارنجی کم‌رنگ، گوشهٔ گرد ۲۸px، آیکون ایموجی درشت.
- **تاریخ‌ها:** دو کادر مشکی با حاشیهٔ نارنجی و فلش ← بینشان (ترتیب راست‌به‌چپ).
- **قیمت:** عدد بزرگ Lalezar نارنجی + «تومان»؛ برای جایزه: قیمت خط‌خورده قرمز + برچسب قرمز «رایگان».
- **CTA:** همیشه یکی؛ «رزرو از لینک بیو».
- **پرداخت:** «پرداخت بعد از تأیید رزرو». کنسلی بعد از پرداخت نداریم.

## ساخت محتوای جدید

1. کپی از `post.html` / `story.html`، فقط متن‌ها، تاریخ‌ها، قیمت و `assets/lake.jpg` را عوض کن.
2. `node brand/viking/render.mjs post` → PNGها در `brand/viking/out/`.
