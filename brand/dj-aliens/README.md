# استوری شب هالووین — DJ Aliens × Viking Offroad

قالبِ یک‌قابیِ استوری (و کراپِ ۴:۵ فید) برای شبِ دومِ هالووین که **DJ Aliens** ستارهٔ آن است. طرح از روی پوسترِ ارسالیِ مالک (`IMG_9140`) بازطراحی شده، نه کپیِ آن: همان اطلاعات، زبانِ بصریِ سینمایی‌تر، و ارزش‌گذاریِ صریح روی خودِ دی‌جی.

| فایل | خروجی |
|---|---|
| `render.py` | `deliverables/dj-aliens-halloween-story.png` — ۱۰۸۰×۱۹۲۰ (۹:۱۶) و `deliverables/dj-aliens-halloween-post.png` — ۱۰۸۰×۱۳۵۰ (۴:۵) |
| `textkit.py` | شکل‌دهی فارسی با HarfBuzz + رسترِ FreeType + ترکیبِ راست‌به‌چپ/چپ‌به‌راست |
| `bidi.py` | تقسیمِ خط به ران‌های RTL/LTR بدون هیچ وابستگی (تست‌شده جدا) |
| `brief.json` | تنها منبعِ متن، تاریخ و ادعاهای کمپین؛ همراه با `source` هر ادعا |
| `assets/desert-night.jpg` | پلیتِ عکسِ کویر شب (تولیدشده با مدل تصویر، بدون متن) |
| `assets/fonts/` | Lalezar + Vazirmatn + Orbitron (هر دو OFL/دارای مجوز) |
| `tests/test_brief.py` | ۱۳ تستِ قراردادِ محتوا، asset و bidi |

## چرا این‌طور ساخته شده
- **بدون مرورگر:** محیطِ ابری Chromium ندارد. این رندرر با Pillow + HarfBuzz کار می‌کند، آفلاین و تکرارپذیر است (`python3 render.py` ⇒ همان پیکسل‌ها).
- **بدون reshaperِ آماده:** فونت‌های برند فرم‌های نمایشیِ عربی ندارند؛ اگر متن را با `arabic_reshaper` بنویسی، همه‌چیز مربع می‌شود. پس shaping با HarfBuzz انجام می‌شود و نامِ لاتین (`ALIENS`) داخل جملهٔ فارسی هم جهتِ خودش را حفظ می‌کند.
- **عکس با کد کشیده نمی‌شود:** پلیت با مدل تصویر ساخته شده و فقط نور/گرِید/تایپوگرافی با کد روی آن می‌آید (قانونِ ریشهٔ مخزن).

## زبان بصری
- پالت: نارنجی `#F39A2B`، مشکی `#141414`، کرم `#FFD9A8`، سفید؛ اکسنتِ کمپین بنفشِ شبانه برای هاله.
- تایپوگرافی: Orbitron برای وردمارک/تکنیکال (`ALIENS`, `BRAND 02`, `4:20`)، Lalezar برای تیترِ فارسی، Vazirmatn Black/Bold/Medium برای متن.
- امضاها: اکولایزرِ نارنجی، کپسولِ `BRAND 02 • UNLOCKED` با قفل، تگِ `4:20 PM`، فریمِ HUD و کدِ لبه‌ها.
- ارزش‌گذاری روی DJ Aliens: تیترِ دوخطیِ «موزیکِ شب، دستِ **DJ ALIENS**»، لاین‌آپ در یک کارتِ تیره، و CTAی نهایی به دایرکت.

## اجرا و بررسی
```bash
pip install -r brand/dj-aliens/requirements.txt
python3 brand/dj-aliens/render.py                    # story + post → deliverables/
python3 brand/dj-aliens/render.py --format story --out /tmp/review
python3 -m unittest discover -s brand/dj-aliens/tests -p "test_*.py"
node scripts/doctor.mjs brand-dj-aliens
```

## حدِ ادعا
- تاریخ («پنجشنبه و جمعه، ۱۴ و ۱۵ آبان»)، برنامهٔ شب، لوکیشن و CTA فقط از پوسترِ مالک آمده‌اند و در `brief.json` با `source` ثبت شده‌اند.
- در این طرح **هیچ** قیمت، ظرفیت، جایزه یا scarcity تازه‌ای ساخته نشده است. اضافه‌کردنِ هر عدد جدید یعنی افزودنِ آن به `brief.json` با منبعِ تأییدشده.
- ساعت `۴:۲۰` امضای تصویریِ پوستر است (تگِ گرافیکی)، نه اعلامِ ساعتِ برنامه؛ اگر مالک ساعتِ واقعی را بدهد، همان باید در `brief.json` بنشیند.
- هویتِ فردی به‌عنوان چهرهٔ تازه ساخته نشده؛ عکسِ پلیت خالی است و نوشته با فونت واقعی روی آن آمده.
