# فیلم موشن «Mega Skills 3000 × Hermes — AI Operating System»

خروجی MP4 افقی 1920×1080 است: ۳۰ فریم بر ثانیه، ۳۷ ثانیه، با موسیقی اختصاصی. برای یوتیوب، لینکدین، ارائه و صفحهٔ اول سایت مناسب است.
روال کار طبق مهارت OpenDesign `motion-design` است: HTML با تایم‌لاین GSAP قطعی (`window.__timelines.main`) → گرفتن فریم‌به‌فریم با Playwright → `ffmpeg`.

| زمان | صحنه | حرکت |
|---|---|---|
| 0–3.2s | اینترو | خط نور کشیده می‌شود، «MEGA SKILLS 3000» از فاصله‌گذاری باز جمع می‌شود و خط به نوار بالا (HUD) تبدیل می‌شود |
| 2.9–9.2s | Hermes × 3000 | اسلاید از تکه‌های خودش ساخته می‌شود: مکعب، تیتر، زیرتیتر، کارت‌ها و بنر |
| 8.95–15.2s | اجرای Local | ورود از درون مکعب (match-cut)، با همان ساخت تکه‌ای |
| 14.95–21.2s | ابزارها و MCP | همان روال |
| 20.95–27.2s | Skill Chaining | همان روال |
| 26.95–33.2s | استراتژی مدل‌ها و Providerها | همان روال؛ در پایان دوربین عقب می‌کشد |
| 33.2–37s | پایان | «هوش مصنوعی فقط پاسخ نمی‌دهد؛ عمل می‌کند» + نشان + «سازمان‌های هوشمندتر، آینده‌ی روشن‌تر» |

- **موتیف:** مکعب «AI OPERATING SYSTEM» در هر اسلاید تکرار می‌شود. دوربین در پایان هر اسلاید به درون آن شیرجه می‌زند و اسلاید بعد از درون مکعب خودش بیرون می‌آید. نوار بالا (HUD) در کل فیلم ثابت می‌ماند.
- **ساخت تکه‌ای:** هر تکه پنجره‌ای به همان عکس و در همان مختصات است. وقتی همه فرود آمدند، اسلاید پیکسل‌به‌پیکسل همان طراحی اصلی است. هیچ متن یا عددی در اسلایدها عوض نشده است.
- **صدا:** `music.py` با numpy آن را می‌سازد: پد، آرپژ ۱۲۰ BPM، ساب، هوش (whoosh) قبل از هر شیرجه و ضربه در هر ورود. قطعه کاملاً اختصاصی است و حق نشر ندارد.
- **فایل‌ها:** `index.html` (سورس قابل ویرایش؛ اگر در مرورگر باز کنی، خودکار پخش می‌شود و با کلیک مکث می‌کند)، `assets/` (۵ اسلاید، `gsap.min.js` 3.14.2، `vazir.woff2`؛ `music.wav` با `music.py` ساخته می‌شود و commit نمی‌شود)، `render.mjs` و `music.py`.

```bash
python3 -I brands/mega-skills-3000/motion/ai-os-film/music.py brands/mega-skills-3000/motion/ai-os-film/assets/music.wav
node brands/mega-skills-3000/motion/ai-os-film/render.mjs /tmp/film            # → /tmp/film/mega-skills-ai-os.mp4 (~4 دقیقه)
node brands/mega-skills-3000/motion/ai-os-film/render.mjs /tmp/film --frames 3.3,6.4,35.5   # فقط چند فریم برای بازبینی
```
خروجی (`out/`، `frames/`، `*.mp4`) commit نمی‌شود.
