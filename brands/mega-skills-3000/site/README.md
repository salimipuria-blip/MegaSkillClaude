# سایت اسکرولی Mega Skills 3000 × Hermes

صفحهٔ زنده (Artifact خصوصی؛ برای دیدن دیگران از منوی Share همان صفحه): https://claude.ai/artifact/E2LBArjP3zE82N2bM8aXHE

- **ساختار:** بالای صفحه HUD ثابت با نوار پیشرفت و فهرست فصل‌ها است، بعد بخش اول و پنج فصل پین‌شده، و در آخر فیلم و جملهٔ پایانی.
- **هر فصل:** اسلاید از تکه‌های هم‌مختصات خودش ساخته می‌شود و بعد از ساخته شدن، پیکسل‌به‌پیکسل همان طرح اصلی است. با اسکرول، دوربین روی تیتر، کارت‌ها و مکعب می‌ایستد و زیرنویس هر توقف متن خود اسلاید است. در پایان دوربین به درون مکعب «AI OS» شیرجه می‌زند و فصل بعد از درون مکعب خودش شروع می‌شود.
- **پایداری موبایل:** `ScrollTrigger.config({ ignoreMobileResize: true })` و ساخت دوباره فقط با تغییر عرض. صفحه هیچ‌وقت اسکرول افقی ندارد (در Playwright روی 1440×900 و iPhone 14 Pro Max بررسی شد).
- **کاهش حرکت:** با `prefers-reduced-motion` پینی در کار نیست؛ اسلایدها کامل و زیرنویس‌ها یک‌جا نشان داده می‌شوند.
- **فایل‌ها:** `index.html` بدنهٔ صفحه است (اسکلت `<html>` را میزبان Artifact اضافه می‌کند)، `assets/s1..s5.jpg` همان پنج اسلاید فیلم است، و GSAP 3.12.5 با SRI از cdnjs بارگذاری می‌شود.
- **ویدیو:** `assets/film.mp4` نسخهٔ وب 720p فیلم است (`../motion/ai-os-film`). commit نمی‌شود؛ با این دستور بازسازی کن:
  `ffmpeg -i mega-skills-ai-os.mp4 -vf scale=1280:720 -c:v libx264 -preset slow -crf 27 -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart assets/film.mp4`
