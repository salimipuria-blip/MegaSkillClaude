# دایرکت (Dayrekt): فونت کپشن فارسی

یک فونت هندسی تک‌خطی که از روی رفرنس «DIRECT / دایرکت» ساخته شده است. ضخامت خط همه‌جا یکی است، گوشهٔ کاسه‌ها گرد و سر خط‌ها صاف است و نقطه‌ها به شکل خط‌تیره‌اند (یک نقطه یک تیرهٔ کوتاه است، دو نقطه یک تیرهٔ بلند، و سه نقطه دو تیره روی هم).

## محتوای پکیج
| مسیر | چیست |
|---|---|
| `fonts/Dayrekt-{Light,Regular,Medium,Bold}.ttf` | فونت برای نصب روی ویندوز/مک و استفاده در CapCut، Premiere، After Effects و Photoshop |
| `fonts/*.woff2` | نسخهٔ وب |
| `captions/dayrekt-captions.ass` | سه استایل زیرنویس آماده: **Dash** (سفید با سایه)، **Label** (متن مشکی روی کادر سفید، شبیه خود رفرنس) و **Bold** (سفید ضخیم با دورخط) |
| `captions/caption.html` + `render.mjs` | قالب کپشن کلمه‌به‌کلمه با انیمیشن: یک تیرهٔ نارنجی زیر کلمه‌ای که گفته می‌شود حرکت می‌کند، یا کادر سفید همراه کلمه‌ها بزرگ می‌شود |
| `caption-demo.mp4` | نمونهٔ ۶ ثانیه‌ای از هر دو سبک، ۱۰۸۰×۱۹۲۰ |
| `specimen.png` | برگهٔ نمونهٔ فونت |
| `src/build_font.py` | سورس فونت: هر حرف به‌صورت مسیر تعریف شده است |

## پوشش
- همهٔ ۳۲ حرف فارسی با چهار حالت اتصال، به‌اضافهٔ آ أ إ ؤ ئ ء ة و لیگاتور «لا»
- اعداد فارسی و انگلیسی، حروف لاتین (حروف کوچک همان شکل بزرگ را دارند)، نشانه‌گذاری فارسی و لاتین، اعراب، و نیم‌فاصله
- ک و ی عربی هم درست نمایش داده می‌شوند
- Presentation Forms هم در فونت هست، تا برنامه‌هایی که خودشان حروف را به هم نمی‌چسبانند هم متن را متصل نشان دهند

## استفاده
- **CapCut / Premiere / AE:** فایل‌های `ttf` را نصب کن (روی ویندوز راست‌کلیک ← Install for all users، روی مک دوبار کلیک ← Install) و برنامه را دوباره باز کن. در CapCut موبایل از گزینهٔ وارد کردن فونت استفاده کن.
- **ffmpeg (سوزاندن زیرنویس روی ویدیو):**
  `ffmpeg -i in.mp4 -vf "subtitles=captions/dayrekt-captions.ass:fontsdir=fonts" -c:a copy out.mp4`
  در libass تگ‌ها (`{\k}` یا `{\c}`) را **وسط** خط فارسی نگذار، چون ترتیب کلمه‌ها به هم می‌ریزد. تگی که اول خط باشد مشکلی ندارد.
- **قالب انیمیشنی:** متن‌ها و زمان‌ها را در آرایهٔ `SCENES` داخل `captions/caption.html` عوض کن، بعد در پوشهٔ `captions` دستور `node render.mjs out.mp4 30` را اجرا کن. پیش‌نیاز: Playwright و ffmpeg.

## پیشنهاد اندازه
اندازهٔ کپشن در ویدیوی عمودی ۱۰۸۰ پیکسل: بین ۹۰ تا ۱۲۰. روی تصویر شلوغ از Medium یا Bold استفاده کن. Light را فقط برای تیتر درشت روی زمینهٔ ساده به کار ببر.

## ساخت دوباره
`pip install fonttools shapely brotli` و بعد `python3 src/build_font.py fonts`
