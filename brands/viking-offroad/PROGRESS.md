# برند وایکینگ آفرود — دفتر جریان پروژه

> توضیح زندهٔ پروژه؛ هر دور کاری همین‌جا اضافه می‌شود. آخرین به‌روزرسانی: **۲۰۲۶-۱۰-۱۴**.

## ۱) پروژه در یک نگاه
- **پوشه:** `brands/viking-offroad/` · دارایی‌های برند (PNG با سورس) — بدون بیلد و بدون تست خودکار
- **شاخص‌های برند:** مشکی/نارنجی (`#F28A1E`)، حال‌وهوای سینمایی گرم؛
  کاورهای هایلایت = عکس لوکیشن با سوژهٔ مرکزی (برای برش دایره‌ای)
- **پک استیکر:** ۳۶۰ عدد تمام‌نارنجی همراه سورس

## ۲) دستور دقیق این پروژه
این پروژه کد اجرایی ندارد؛ «بررسی» یعنی صحت فایل‌ها و ارجاع‌هایشان:
```bash
ls brands/viking-offroad/stickers/packs | head
python3 - <<'PY'
import json,pathlib
for m in pathlib.Path('brands/viking-offroad').rglob('*.json'):
    json.loads(m.read_text())   # هر JSON معیوب خطا می‌دهد
    print('ok', m)
PY
```
اگر استیکر یا کاور جدید اضافه می‌شود: همان نام‌گذاری و همان پالت، و لینک‌دادنش در
`pack` مربوطه به‌روز شود.

## ۳) وضعیت تأییدشده (۲۰۲۶-۱۰-۱۴)
| بررسی | نتیجه |
|---|---|
| فایل‌های متادیتا (JSON) | ✅ همه پارس می‌شوند |
| حجم/ساختار پک‌ها | ✅ پک‌های پیش‌نمایش و سورس سرجایشان هستند |
| تست خودکار | – ندارد (پروژهٔ دارایی است، نه برنامه) |
