DeepSeekِ لوکالت را به‌عنوان بازبینِ مستقل اجرا کن — هرکس ساخت، خودش نمره نمی‌دهد. تماماً در مرورگر، بدون نصب. تأییدِ ناسالم یا خطا = BLOCKED/FAIL، نه تأیید.

هنوز اجرایی ثبت نشده.
راه‌اندازیِ DeepSeek روی سیستم خودت (ویندوز)

Ollama: نصب از ollama.com، بعد ollama run deepseek-r1. چون این صفحه از دامنهٔ دیگری صداش می‌زند، باید CORS را باز کنی:

setx OLLAMA_ORIGINS "*"
# بعد Ollama را از System Tray ببند و دوباره باز کن

Endpoint می‌ماند http://localhost:11434/v1.

LM Studio: مدل را load کن، در تب Developer سرور را Start کن (CORS به‌صورت پیش‌فرض باز است). Endpoint را به http://localhost:1234/v1 تغییر بده.

اگر «خطای اتصال/CORS» دیدی: مطمئن شو سرور روشن است و برای Ollama متغیر بالا را گذاشته‌ای.
