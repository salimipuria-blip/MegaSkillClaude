# کنسول آیفون مگااسکیل (`mobile/`)

وب‌اپ فارسی (PWA) برای بازکردن همین مخزن در **VS Code آنلاین**، جست‌وجوی آفلاین مهارت‌ها و کپی دستور تست پروژه‌ها. مهارت همراه آن: `online-vscode-mobile-coding` در `library/skills/`.

## استفاده روی آیفون
1. صفحه را با Safari از یک هاست HTTPS باز کن.
2. Share ← **Add to Home Screen** تا مثل اپ نصب شود.
3. تب «مهارت‌ها»: عبارت را فارسی/فینگلیش/انگلیسی بنویس، حوزه را در صورت نیاز فیلتر کن و مهارت را باز کن.
4. «کپی پرامپت آماده» را در Claude پیست کن یا فایل مهارت را در VS Code باز کن.
5. تب «پروژه‌ها» یا «عملیات» دستور دقیق تست هر پروژه را نشان می‌دهد. VS Code وب روی آیفون ترمینال ندارد؛ دستورها را در ترمینال ابری اجرا کن.

## منبع حقیقت و تولید ایندکس
- منبع canonical: `.claude/skills/mega-skills-router/references/triggers.json`.
- `mobile/skills-index.json` تولیدی است؛ دستی ویرایش نشود.
- `mobile/sw.js` شامل cache key تولیدی است؛ دستی cache key را تغییر نده.
- پس از تغییر مهارت‌ها یا هر فایل precache‌شدهٔ PWA، از ریشه اجرا کن:

```bash
python3 mobile/build-index.py          # بازسازی index و fingerprint کش
python3 mobile/build-index.py --check  # بررسی drift بدون نوشتن
node --test mobile/search.test.mjs     # رتبه‌بندی، نرمال‌سازی، escape و اعتبارسنجی مسیرها
node --check mobile/app.js
node --check mobile/sw.js
```

`build-index.py` علاوه بر ایندکس، fingerprint محتوایی از فایل‌های آفلاین و منطق Service Worker محاسبه می‌کند. با تغییر هرکدام، نام کش عوض می‌شود و اپ در نصب/به‌روزرسانی بعدی نسخهٔ جدید را می‌گیرد. پاک‌سازی فقط کش‌های `mega-mobile-*` را حذف می‌کند و cache سایر اپ‌های همان origin را دست‌نخورده می‌گذارد.

## جست‌وجو و امنیت رابط

جست‌وجو روی دستگاه انجام می‌شود و ایندکس فعلی **۵٬۷۴۵ مهارت قابل‌مسیریابی** دارد. `search.mjs` توکن‌ها را فقط یک‌بار پیش‌محاسبه می‌کند؛ متن ایندکس پیش از قرارگرفتن در HTML escape و payload هنگام بارگیری از نظر schema و مسیر canonical بررسی می‌شود. هیچ کلید یا درخواست خصوصی در این PWA لازم نیست.

## چرا همکار مهارت را خودکار دارد؟
- مسیریاب در `.claude/skills/mega-skills-router/` داخل همین ریپو است؛ بازکردن مخزن در VS Code/Claude Code کافی است.
- همان مهارت در ایندکس canonical ثبت و با `scripts/sync_skill_library.py` به پلاگین قابل‌نصب منتقل می‌شود.
- افزونه‌های پیشنهادی VS Code در `.vscode/extensions.json` تعریف شده‌اند.

## محدودیت‌های انتشار
- استقرار باید HTTPS باشد تا Service Worker فعال شود (به‌جز localhost برای توسعه).
- این کنسول دستورها را روی گوشی اجرا نمی‌کند و دادهٔ جست‌وجو/تاریخچهٔ کاربر را به سرور نمی‌فرستد.
- اگر کاربر PWA را مدت طولانی آفلاین نگه دارد، نسخهٔ نصب‌شده تا اتصال بعدی به اینترنت روی همان نسخه می‌ماند؛ پس از reconnect کش نسخه‌دار تازه می‌شود.
