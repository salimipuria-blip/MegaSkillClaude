# اجرای مگااسکیل در VS Code و Netlify

این مسیر، برنامهٔ موجود `apex-agent` را به نمایهٔ ۵٬۹۶۴ مهارت وصل می‌کند. منبع اصلی مهارت‌ها و فایل‌های همراه در ساختار قبلی مخزن باقی می‌ماند. خروجی وب فقط متن مهارت‌ها، برنامه و مجوزها را منتشر می‌کند؛ اسکریپت‌های ثالث و فایل‌های توسعه منتشر نمی‌شوند.

## VS Code

فایل `MegaSkills.code-workspace` را باز کنید و F5 بزنید. ابتدا خروجی ساخته می‌شود؛ سپس سرور Node روی پورت 8080 با دیباگر اجرا می‌شود. افزونهٔ Node جداگانه لازم نیست.

معادل ترمینال، از پوشهٔ `apex-agent`:

```bash
npm run build
npm run serve -- --root dist --port 8080
```

آدرس محلی: `http://localhost:8080`.

## Netlify

مخزن را در Netlify وارد و شاخهٔ حاوی این تغییرات را انتخاب کنید. فایل `netlify.toml` ریشه، پوشهٔ پایه، دستور ساخت، خروجی `dist` و تابع پروکسی را مشخص می‌کند. ساخت بدون نصب وابستگی اجرایی انجام می‌شود. برای انتشار همراه تابع سروری، از اتصال Git یا Netlify CLI استفاده کنید؛ آپلود پوشهٔ استاتیک به‌تنهایی تابع را مستقر نمی‌کند.

بدون کلید، اجرای محلی Reflex برای خانواده‌های از پیش پیاده‌سازی‌شده فعال است. تولید کد عمومی با مدل واقعی، به ارائه‌دهندهٔ متصل نیاز دارد. مدل انتخاب‌شده متن حداکثر دو مهارت مرتبط را به‌عنوان دادهٔ مرجع دریافت می‌کند. متن مهارت مجوز اجرای برنامه، دسترسی به حساب یا جایگزینی قوانین سیستم نیست.

پروکسی اختیاری است و تا تنظیم `APEX_PROXY_TOKEN` و `APEX_UPSTREAM_KEY` در محیط Netlify غیرفعال می‌ماند. هیچ کلیدی در خروجی ساخت قرار نمی‌گیرد.

## بررسی

```bash
npm run build
npm test
npm run check
```

تست‌های DOM نیاز به `jsdom` دارند؛ در محیط توسعه با `npm install --no-save --no-package-lock --ignore-scripts jsdom` نصب کنید. تست‌های مرورگر واقعی به بسته‌های ذکرشده در README نیاز دارند. تست مدل با پاسخ HTTP محلی، تأیید ارتباط با ارائه‌دهندهٔ واقعی نیست.
