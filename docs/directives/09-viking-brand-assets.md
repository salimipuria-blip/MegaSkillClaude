# 09 — دارایی‌های برند وایکینگ آفرود (`brands/viking-offroad/`, `brand/viking/`)

## مأموریت و مرزها
مرجع دارایی‌های بصری برند viking.offroad (تور آفرود و کمپ): پک‌های استیکر، کاور هایلایت، لوگو و فونت. هویت ثابت: **مشکی + نارنجی ‎#F28A1E، حال‌وهوای سینمایی گرم**. این بخش «کد محصول» نیست؛ کیفیت و یکدستی خروجی تصویری معیار است.

## وضعیت فعلی (شواهد: `brands/viking-offroad/stickers/`, `CLAUDE.md`)
- ✅ ۱۲ پک × ۳۰ استیکر = ۳۶۰ استیکر تمام‌نارنجی با سورس (`packs/pack-01-*` تا `pack-12-*`) + پیش‌نمایش هر پک.
- ✅ فونت‌ها (Lalezar, Vazirmatn) و لوگو در `brand/viking/assets/`؛ رندر صفحات برند با `brand/viking/render.mjs`.
- قاعدهٔ کاور هایلایت: عکس لوکیشن با رنگ‌بندی نارنجی گرم و لبهٔ تیره، سوژه در مرکز برای برش دایره‌ای.

## خط لولهٔ کار (به‌جای اجرا/تست کدی)
```bash
ls brands/viking-offroad/stickers/packs/          # ساختار پک‌ها و شماره‌گذاری
node brand/viking/render.mjs                       # رندر صفحات برند (post/story)
```

## پروتکل بازبینی و دیباگ تصویری (حرفه‌ای)
1. **قانون ساخت عکس:** تصویر با کد (SVG/آیکون دستی) ساخته نمی‌شود؛ کد فقط برای دانلود، تحویل و گذاشتن متن فارسی روی عکس است. متن فارسی داخل تصویر تولیدی به‌صورت جداگانه با فونت Vazirmatn روی عکس قرار می‌گیرد.
2. هر خروجی قبل از تحویل چشمی بازبینی شود: متن غلط، چهرهٔ ساختگی، دست خراب، کادر نامناسب یا رنگ خارج از پالت (#F28A1E) = ساخت مجدد، نه تحویل.
3. چهرهٔ ساختگی و متن انگلیسی روی عکس نیاید مگر کاربر صریحاً بخواهد.
4. نام‌گذاری و شماره‌گذاری پک‌ها (`NN.png` ترتیبی) حفظ شود؛ فایل بدون پیش‌نمایش به‌روز به پک اضافه نشود.
5. لینک Canva/Figma به‌تنهایی تحویل محسوب نمی‌شود (برای کاربر باز نمی‌شود)؛ فایل نهایی باید به دست کاربر برسد.

## گسترش (اولویت‌بندی)
- **P1:** اسکریپت تکرارپذیر ساخت پیش‌نمایش همهٔ پک‌ها و بررسی خودکار ابعاد/حجم/نام‌گذاری (Node سبک) تا خطای دستی وارد پک نشود.
- **P1:** چک‌لیست انتشار هر پک (تعداد، پیش‌نمایش، پالت رنگ، نمونهٔ چاپ/استیکر واقعی).
- **P2:** کاتالوگ قابل جست‌وجوی دارایی‌ها (ایندکس Markdown/HTML سبک) برای پیدا کردن سریع استیکر و کاور.

## Definition of Done
فایل نهایی بازبینی چشمی شده، پالت و نام‌گذاری درست، پیش‌نمایش پک به‌روز، و خروجی به‌صورت فایل تحویل داده شده است — نه فقط لینک.
