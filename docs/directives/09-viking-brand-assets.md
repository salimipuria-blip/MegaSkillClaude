# 09 — دارایی‌های استیکر وایکینگ (`brands/viking-offroad/`)

## مأموریت و مرز محصول
مرجع فایل‌های نهایی استیکرهای برند وایکینگ آفرود است؛ اپلیکیشن اجرایی یا سرویس آنلاین نیست. خروجی نهایی PNG شفاف است و معیار کیفیت شامل تعداد، شماره‌گذاری، اندازه، کانال alpha و بازبینی چشمی می‌شود. قالب‌های پست/استوری در `brand/viking/` پروژهٔ جداگانه‌اند و دستورشان در [10-viking-content-renderer.md](10-viking-content-renderer.md) است.

## وضعیت فعلی مبتنی بر شواهد
- ۱۲ پک، هرکدام ۳۰ استیکر: **۳۶۰ PNG** با ابعاد ۵۱۲×۵۱۲ و کانال alpha.
- ۱۲ پیش‌نمایش و یک کاور در `stickers/packs/` و `stickers/cover/`.
- سورس ساخت در `stickers/src/`؛ خروجی PNG را دستی جایگزین سورس نکن.
- هویت پک استیکر: نارنجی `#F28A1E`، زمینهٔ شفاف و فایل‌های ترتیبی `01.png` تا `30.png`.

## دستورهای اجرا و بررسی
از ریشهٔ مخزن:

```bash
python3 scripts/check_brand_assets.py --stickers  # ۱۲ پک، ۳۶۰ PNG، پیش‌نمایش و کاور
```

بازسازی خروجی‌ها فقط در محیط دارای Node.js، `playwright-core` و Chromium:

```bash
cd brands/viking-offroad/stickers/src
npm install --no-package-lock
CHROMIUM_PATH=/path/to/chromium node render.js all
# برای پک‌های مشخص (شماره‌گذاری صفرمبنا در سورس):
CHROMIUM_PATH=/path/to/chromium node render.js 0,2 --sheets
```

`CHROMIUM_PATH` باید مسیر اجرایی مرورگر باشد. بعد از ساخت، بررسی ایستا و بازبینی تصویری هر پیش‌نمایش الزامی است؛ بررسی header PNG جای مشاهدهٔ واقعی تصویر را نمی‌گیرد.

## پروتکل دیباگ و کنترل کیفیت
1. ابتدا `python3 scripts/check_brand_assets.py --stickers` اجرا کن؛ پیام خطا شمارهٔ پک، نام فایل یا ابعاد مورد انتظار را مشخص می‌کند.
2. اگر PNG ناقص است، سورس همان پک (`packs.js`, `duos.js`, `character.js`, `female.js`, `stickers.html`) را اصلاح و فقط همان پک را بازسازی کن؛ فایل PNG را با ادیت دستی یا تغییر نام تصادفی «درست» نکن.
3. اگر رندر با Playwright/Chromium شکست خورد، مسیر ماژول `playwright-core` و `CHROMIUM_PATH` را جداگانه بررسی کن؛ کلید یا راز سرویس در این پروژه لازم نیست.
4. خروجی را از نظر شفافیت، بریدگی، خوانایی فارسی، ترتیب ۰۱–۳۰، سازگاری رنگ با پالت و تطابق preview با PNGها چشمی بررسی کن.
5. ادعای «۳۶۰ استیکر آماده» فقط وقتی مجاز است که validator و بازبینی تصویری هر دو پاس شوند.

## گسترش اولویت‌بندی‌شده
- **P1:** ساخت `MANIFEST.json` از سورس با تعداد، نام فایل‌ها، ابعاد و SHA-256؛ تولید manifest باید قطعی و قابل بازسازی باشد.
- **P1:** افزودن تصاویر representative به چک بصری انتشار؛ ابزار ایستا پیکسل/کیفیت طراحی را ارزیابی نمی‌کند.
- **P2:** ساخت صفحهٔ کاتالوگ فقط اگر نیاز واقعی به جست‌وجوی پک‌ها ایجاد شد؛ دارایی خام را به محصول وب تبدیل نکن.

## Definition of Done
`python3 scripts/check_brand_assets.py --stickers` سبز؛ هر پک ۳۰ PNG شفاف ۵۱۲×۵۱۲ دارد؛ ۱۲ preview و cover معتبرند؛ خروجی بازبینی چشمی شده؛ `brands/viking-offroad/PROGRESS.md` با نتیجه و کار باز به‌روز است.
