# 08 — کتابخانه و مسیریاب مهارت‌ها (`library/`, `plugins/`, ریشه)

## مأموریت و مرزها
منبع مهارت‌های Claude (هزاران `SKILL.md`) و مسیریاب Mega Skills که برای هر درخواست، مهارت مرتبط را پیدا می‌کند. مصرف‌کننده‌ها: موتور `psk/`، هرمس و Claude Code. **یک منبع حقیقت** وجود دارد و بقیهٔ نسخه‌ها از آن sync می‌شوند؛ ویرایش دستی نسخه‌های کپی ممنوع.

## وضعیت فعلی (شواهد: `scripts/sync_skill_library.py`, `docs/REPO_HARDENING.md`)
- ✅ `sync_skill_library.py` نمایه، دستورالعمل، فایل همراه و متن مجوز را از منبع اصلی به پلاگین قابل‌نصب (`plugins/mega-skills-router`) همگام می‌کند؛ `--check` در CI ناهماهنگی را fail می‌کند.
- ✅ ۵٬۷۰۵ مهارت قابل مسیریابی؛ ۲۸۱ مهارت ناقص نگه داشته شده ولی از مسیریابی پیش‌فرض کنار گذاشته شده‌اند (`--include-incomplete` فقط برای بررسی دستی).
- تست‌های ریشه: `test_mega_skills_router.py`, `test_skill_library_sync.py`, `test_statusline.py` + بنچمارک/golden مسیریابی در `psk/`.

## اجرا و تست
```bash
python3 scripts/sync_skill_library.py --check       # بدون نوشتن؛ اختلاف = خطا
python3 scripts/sync_skill_library.py               # sync واقعی (فقط از منبع اصلی)
python3 -m unittest discover -s tests -v
python3 scripts/verify_skills.py                    # یکپارچگی مهارت‌ها
```

## پروتکل دیباگ حرفه‌ای
- **مهارت پیدا نمی‌شود:** ترتیب بررسی: وجود در منبع اصلی → کامل‌بودن (frontmatter) → حضور در index → امتیاز مسیریاب. مهارت ناقص را برای «رفع مشکل» کامل فرض نکن و بی‌سروصدا وارد مسیریابی نکن.
- **ناهماهنگی sync:** `--check` را اجرا و اولین diff را بگیر؛ فایل مقصد را دستی اصلاح نکن — منبع را اصلاح و sync کن، وگرنه CI دوباره قرمز می‌شود.
- **رگرسیون دقت:** با golden و بنچمارک `psk` قبل/بعد را مقایسه کن؛ تغییر الگوریتم بدون عدد قبل/بعد قبول نیست.
- فایل‌های تولیدی (ZIP، خروجی build هرمس) را commit نکن؛ مجوز مهارت‌های ثالث در `_licenses` نگه داشته شود.

## گسترش (اولویت‌بندی)
- **P1:** مجموعهٔ طلایی فارسی بزرگ‌تر برای مسیریاب و سنجش دقت در CI (هدف ≥ ۸۰٪) مشترک با `psk/`.
- **P1:** تکمیل یا حذف آگاهانهٔ ۲۸۱ مهارت ناقص با گزارش دوره‌ای (کدام‌ها، چرا ناقص‌اند).
- **P2:** فشرده‌سازی/ایندکس سبک‌تر برای مصرف موبایل؛ حذف نسخه‌های تکراری فقط با اثبات اینکه نصب مستقل خراب نمی‌شود.

## Definition of Done
`sync --check` بدون اختلاف، تست‌های ریشه سبز، دقت مسیریابی پسرفت نکرده، هیچ ویرایش دستی روی خروجی sync وجود ندارد.
