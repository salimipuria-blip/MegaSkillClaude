# 06 — BISON Brand Book (`bison-brand-book/`)

## مأموریت و مرزها
کتاب برند دیجیتال بایسون: تجربهٔ اسکرول سینمایی (Vite + GSAP + Lenis) با دموی زندهٔ دسکتاپ/موبایل. خروجی اصلی «سند برند قابل ارائه» است؛ سنگین‌سازی انیمیشن به قیمت خوانایی/دسترس‌پذیری ممنوع.

## وضعیت فعلی (شواهد: `package.json`, `ROADMAP.md`)
- ✅ بیلد سبز؛ آسیب‌پذیری زمان بیلد `source-map-js` رفع شده (`npm audit` صفر).
- ⚠️ **هیچ تست خودکاری ندارد** (فقط `build` در CI)؛ انتشار هنوز دوکاناله است (GitHub Pages + Vercel از مخزن قدیمی) و باید یکی شود.
- دارایی‌ها: `public/` (تصاویر، لوگوها، ZIP کتاب برند)، سیستم طراحی در `design-system/`، راهنما در `docs/brand-guidelines.md`.

## اجرا و تست
```bash
cd bison-brand-book && npm ci && npm run build
npm audit                       # باید صفر بماند
npm run dev                     # بررسی دستی اسکرول/موبایل (پورت 5173)
```

## پروتکل دیباگ حرفه‌ای
- **شکست بیلد:** سابقه نشان داده نشانگر ادغام نیمه‌کاره (`<<<<<<<`) در `index.html` بیلد را می‌شکند؛ اول `grep -R '<<<<<<<' .` بعد سراغ Vite برو.
- **پرش/گیر اسکرول:** انیمیشن را لایه‌ای ایزوله کن: Lenis خاموش → GSAP خاموش → CSS. پروفایل Performance مرورگر (نه حدس)؛ انیمیشن روی `transform/opacity` بماند و layout thrash (خواندن/نوشتن پشت‌سرهم DOM) حذف شود.
- **موبایل:** در عرض ۳۲۰px اسکرول افقی ممنوع؛ تصاویر hero با سایز پاسخ‌گو و `loading` درست؛ LCP هدف < ۲٫۵ ثانیه روی موبایل.
- **دسترس‌پذیری:** `prefers-reduced-motion` باید انیمیشن سینمایی را خاموش کند؛ کنتراست متن روی تصویر AA.

## گسترش (اولویت‌بندی)
- **P0:** یکپارچه‌سازی انتشار روی Vercel همین مخزن (Root Directory=`bison-brand-book`) و خاموش‌کردن Pages قدیمی.
- **P1:** افزودن تست دود (smoke) بیلد + بررسی لینک/تصویر گمشده در CI (اسکریپت Node سبک، بدون وابستگی سنگین)؛ بهینه‌سازی وزن تصاویر `public/images/`.
- **P2:** استخراج توکن‌های برند (آهن/طلا) به فایل tokens مشترک با بقیهٔ پروژه‌ها؛ نسخهٔ چاپی/PDF کتاب برند از همان منبع.

## Definition of Done
`npm run build` و `npm audit` سبز، بررسی دستی دسکتاپ+موبایل (اسکرول، reduced-motion، ۳۲۰px) انجام و ثبت‌شده، فقط یک نسخهٔ زنده باقی مانده باشد.

## پروندهٔ واقعی این دور (۲۰۲۶-۱۰-۱۴) — ارجاعِ نسبی و نخستین قرارداد ایستا

**باگ:** `index.html:48` لینکِ دانلودِ ZIP به‌صورت **نسبی** (`href="BISON-Brand-Book.zip"`) بود در حالی که بقیهٔ دارایی‌ها root-absolute هستند (`/favicon.svg`, `/images/*`) و `public/download.html` هم از `/BISON-Brand-Book.zip` استفاده می‌کند. مسیرِ نسبی روی ریشه کار می‌کند، اما با سرو از هر زیرمسیر می‌شکند — و این دقیقاً همان چیزی است که با انتقالِ Vercel (بندِ P0) پیش می‌آید. ضمناً مستنداتِ پروژه ادعا می‌کرد همهٔ ارجاع‌ها root-absolute هستند؛ یعنی **driftِ مستندات** هم بود.

**چطور پیدایش کنی (دستورِ دائمی):**
```bash
grep -oE '(src|href)="[^"]+"' bison-brand-book/index.html | sort -u
```
هرچه با `/` شروع **نشود** و `#`/`http`/`mailto` نباشد، یک بمبِ ساعتی است.

**قرارداد ایستای جدید (`tests/static.test.mjs`، ۸ تست، از طریق `npm test`):** همهٔ ارجاع‌های محلی root-absolute؛ هر ارجاعِ `/...` در `public/` وجود دارد؛ ZIP واقعاً ZIP است (امضای `PK` — فایلِ خالی یا HTMLِ خطا رد می‌شود)؛ هر لنگر به یک `id` می‌رسد (۱۰ لنگر؛ قبلاً هیچ‌کدام تست نمی‌شدند)؛ entry pointها وصل‌اند؛ کلیدِ سرویس در فرانت‌اند نیست؛ `prefers-reduced-motion` هم در CSS و هم در JS؛ پوشه‌های تصویر/لوگو موجودند.

**چرا reduced-motion در این پروژه حیاتی است:** GSAP + Lenis کلِ تجربه را می‌رانند. بدون گارد، صفحه برای کاربرِ حساس به حرکت عملاً غیرقابل استفاده است؛ پس این تست یک بندِ دسترس‌پذیری است، نه وسواس.

**تأیید با جهش:** برگرداندنِ همان ارجاع نسبی در یک کپیِ موقت، دقیقاً تستِ «root-absolute» را قرمز کرد.

**دستورِ کامل این پروژه:**
```bash
node scripts/doctor.mjs bison-brand-book   # قرارداد + بیلد + audit
cd bison-brand-book && npm ci && npm test && npm run build && npm audit --omit=dev
```
