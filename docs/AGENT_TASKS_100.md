# ۱۰۰ تسک حرفه‌ای برای ایجنت — مخزن MegaSkillClaude

> نسخه: ۲۰۲۶-۱۰-۲۰ · منبع: صف کار `CLAUDE.md` هر پروژه + ممیزی ۱۸ تا ۲۰ مهر.
> هر تسک = یک PR جدا، کوچک و قابل بازبینی. ترتیب پیشنهادی: از بالا به پایین (P0 → P2).

## قوانین ثابت (قبل از هر تسک بخوان)

1. **قبل از کار:** `CLAUDE.md` ریشه + `CLAUDE.md` همان پوشه را بخوان. اعداد را از منبع canonical بخوان، نه از حافظه.
2. **فقط PR پیش‌نویس بساز؛ هرگز merge نکن.** merge فقط با مالک است. force-push، rebase روی main، حذف شاخه/فایل/مخزن ممنوع.
3. **هیچ secret** (توکن، کلید، رمز، `service_role`) در کد، تست، لاگ، PR یا چت. secretهای هرمس فقط در Cloudflare Secrets. نام secret یا binding را بدون تأیید مالک عوض نکن.
4. **هیچ اقدام زنده بدون تأیید:** deploy، migration روی دیتابیس واقعی، seed، فعال‌سازی سرویس پولی، تغییر تنظیمات Vercel/Cloudflare/Supabase.
5. **تست اول (TDD):** تست قرمز → پیاده‌سازی → سبز. «انجام شد» فقط با خروجی واقعی تست. چیزی که اجرا نشد صریحاً `NOT RUN` بنویس.
6. **قبل از PR:** تست‌های همان پروژه (فهرست در `CLAUDE.md` ریشه) + `python3 -m unittest discover -s tests` + `python3 scripts/scan_secrets.py`.
7. **بعد از هر تغییر:** `CLAUDE.md` + `PROGRESS.md` (مدخل تاریخ‌دار) + `PROFESSIONAL_GUIDE.md` همان پوشه؛ در صورت تغییر وضعیت، `docs/PORTFOLIO.md`.
8. **عکس هرگز با کد طراحی نشود** (نه SVG، نه آیکون دستی). متن فارسی روی عکس فقط با Vazirmatn.
9. **داده نساز:** ادعای بی‌منبع (قیمت، ظرفیت، تاریخ، آمار) را پر نکن؛ باز بگذار و بنویس «منتظر مالک».
10. شناسهٔ مدل در commit/PR ننویس. پیام commit کوتاه و انگلیسی؛ بدنهٔ PR فارسی با بخش «چرا / چه / تست / NOT RUN».
