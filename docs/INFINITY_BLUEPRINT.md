# نقشهٔ Infinity Mega Skill

> نام پروژه برای همیشه **Infinity Mega Skill** است. شناسهٔ فنی‌اش (پوشه، پلاگین، پکیج) `infinity-mega-skill` است. هر نام دیگری (MegaSkillClaude، mega-skills-router، MEGA SKILLS 3000، psk، apex-agent، مِتاکد) فقط نام قدیمی است و طبق فاز ۱ حذف می‌شود.

## ایده در یک جمله
یک مخزن، یک مغز، یک بانک: هر درخواست اول به **روتر** می‌رسد. روتر **مهارت** درست را از کتابخانهٔ ۵٬۹۶۴ مهارت برمی‌دارد، **ایجنت** مناسب آن جایگاه را با امتیاز از بانک ایجنت‌ها انتخاب می‌کند و **مدل** رایگانِ سالم و سریع را از بانک LLM می‌گیرد. «داکتر» قبل و بعد از هر کار همه‌چیز را تست می‌کند.

```
درخواست ─► روتر ─► مهارت (library/) ─► ایجنت (registry/agents.json) ─► مدل (registry/models.json)
                                   ▲                                    │
                                   └──────── داکتر و نگهبان ◄───────────┘
```

## ۱. ساختار واحد (هدف نهایی، در یک مخزن)

| لایه | پوشهٔ هدف | الان کجاست |
|---|---|---|
| هسته: روتر و کتابخانهٔ مهارت | `core/router/`، `core/skills/` | `plugins/mega-skills-router/`، `library/`، `.claude/skills/` |
| بانک‌ها (LLM، ایجنت، رفتار) | `registry/` | **ساخته شد** |
| ایجنت‌ها | `agents/hermes/`، `agents/coder/` | `hermes/`، `infinity-mega-skill/`، `infinity-loop/`، `orchestrator/` |
| اپ‌ها و سایت‌ها | `apps/<name>/` | `psk/`، `lithos/`، `fjcod/`، `viking-team/`، `mobile/`، `bison-brand-book/` |
| برندها و دارایی‌ها | `brands/<brand>/` | `brands/`، `brand/` |
| داکتر و نگهبان | `scripts/doctor.mjs`، `scripts/verify.mjs`، `tests/` | موجود؛ گسترش می‌یابد |
| مستندات | `docs/` | پراکنده؛ یکی می‌شود |

جابه‌جایی پوشه‌ها مسیر Vercel/Cloudflare را می‌شکند. پس هر پروژه جدا منتقل می‌شود: اول Root Directory در Vercel/Cloudflare عوض می‌شود، بعد پوشه.

## ۲. داکتر و نگهبان
- **پیش از push:** `node scripts/verify.mjs` (هست). بعد از این، تست بانک‌ها (`tests/test_infinity_registry.py`) هم در job `router` اجرا می‌شود.
- **روزانه:** `node scripts/registry/refresh_free_models.mjs` فهرست زندهٔ مدل‌های رایگان را می‌سازد. مدلی که حذف شده باشد پیش از آنکه هرمس با 404 به آن بخورد، از فهرست بیرون می‌رود.
- **استاندارد کد:** TypeScript/ESM برای وب و Worker، Python 3.12 برای ابزار و تست، بدون وابستگی اضافه. هیچ «انجام شد»ی بدون خروجی دیده‌شده پذیرفته نمی‌شود.

## ۳. معیار انتخاب ایجنت برای هر جایگاه
هر ایجنت در `registry/agents.json` با شش معیار ثبت می‌شود: هزینه، متن‌باز بودن، توان ساخت زیرایجنت، کیفیت فارسی، فراخوانی ابزار و دسترسی از ایران. هر جایگاه (هماهنگ‌کننده، کدنویس، نگهبان، پژوهشگر، طراح، محتوای فارسی، کار انبوه) وزن خودش را دارد. امتیاز هر ایجنت جمع وزن‌دار همین معیارهاست.

نمونه: **Hermes Agent** (از Nous Research، متن‌باز) برای هر تسک زیرایجنت می‌سازد و مهارت جدید می‌نویسد، پس برای جایگاه «هماهنگ‌کننده» بهترین امتیاز را دارد. **OpenCode** برای کد انبوه ارزان است و همین حالا با DeepSeek V4.1 Flash در دسترس است. **Claude Code** گران است، پس فقط معمار و بازبین نهایی می‌ماند.

## ۴. بانک LLM رایگان
- `registry/providers.json`: ۱۷ ارائه‌دهنده (OpenRouter، Hugging Face، GitHub Models، Groq، Cerebras، Mistral، Gemini، Pollinations، Cloudflare Workers AI، NVIDIA NIM، SambaNova، Cohere، DeepSeek، Ollama، 9router، OmniRoute و LMArena). هر سطر نشان می‌دهد زنده بررسی شده یا فقط از روی مستندات آمده.
- `registry/models.json`: فهرست زنده. در اجرای امروز ۱۵۱ مدل خوانده شد: ۱۷ مدل رایگان OpenRouter و ۱۳۴ مدل Hugging Face با سرعت و قیمت هر ارائه‌دهنده، از جمله کل خانوادهٔ DeepSeek (V4.1 Flash، V4 Pro، R1).
- **LMArena جای درستش:** API تولیدی نیست. فقط برای انتخاب مدل هر جایگاه و مقایسهٔ کورِ رفتارِ کلون‌شده با نسخهٔ اصلی به کار می‌رود.

## ۵. کلون رفتار (برای ایجنت‌های پولی مثل Manus)
وزن و کد بسته را نمی‌شود کپی کرد. چیزی که کپی می‌شود **رفتار** است:
1. **پروفایل رفتار** (`registry/behaviors/<id>.json`): پرامپت سیستم، مراحل کار، سیاست ابزار، قالب خروجی.
2. **مجموعهٔ آزمون:** ۲۰ تسک واقعی که خروجی نسخهٔ اصلی برایشان ثبت شده است.
3. **اجرا روی مدل رایگان** (مثلاً DeepSeek V4.1 Flash) و **مقایسهٔ کور** به روش LMArena. پروفایل فقط وقتی پذیرفته می‌شود که برد آن دست‌کم ۴۵٪ باشد.
