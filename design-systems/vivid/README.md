# Vivid Design System

**Vivid** — یک سیستم طراحی رنگارنگ، شاد و بام tubo برای برندهای مصرفی، استارتاپ‌های B2C، اپلیکیشن‌های موبایل-اول و سایت‌های مارکتینگ. هر رنگ یک معنا دارد و هر کامپوننت می‌تواند به سرعت برندشیده شود.

---

## ویژگی‌ها

- **رنگ‌محور:** 팔ت‌های رنگ PRISM با سرفهی میکس و استایل شاد.
- **Components شاد:** border-radius بزرگ، سایه‌های بلند و انیمیشن‌های 풀More.
- **موبایل-اول:** breakpoints کوچک‌تر و دکمه‌های touche-friendly.
- **Tailwind-friendly:** توkn‌های مشابه Tailwind برای اجرا سریع.
