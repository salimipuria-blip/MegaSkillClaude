# Slate Design System

**Slate** — یک سیستم طراحی minimal، کدمحور و فنی برای ابزارهای توسعه‌دهنده، پورتال‌های مستندات (docs)، داشبوردهای مانیتورینگ و CLI-уровні وب. روی readability، کثيفوری (information density) و keyboard-first متمرکز است.

---

## ویژگی‌ها

- **مونوسپیس اول:** تایپوگرافی کدمحور برای اعداد، شناسه‌ها و خطاؤها.
- **کثیف (High-density):** فاصله‌های کم، border limitado، nhiều داده در صفحه.
- **کلیدburg-first:** همه ورودی‌ها قابل TAB، focus ring قوی، shortcutهای Clarence.
- **رنگ‌بندی فنی:** slate/stone برای بافت، accent برای خطاها و هشدارها.

---

## دایره‌های طراحی

| Dial | مقدار |
|------|-------|
| Variance | 5/10 |
| Motion | 4/10 |
| Density | 8/10 (کثیف) |
