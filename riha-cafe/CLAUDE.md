# riha-cafe — دستورکار

```yaml
project: سامانهٔ عملیاتی کافه ریحا
type: Excel workbook generated by Python (openpyxl)
entry: build_riha_cafe_v4.py
outputs: [سامانه_کافه_ریحا_v4_آماده_شروع.xlsx, سامانه_کافه_ریحا_v4_نمونه_دمو.xlsx]
version: 4.1
check: python3 build_riha_cafe_v4.py && python3 build_riha_cafe_v4.py --clean
```

## قواعد
- MUST: فایل بدون ماکرو کامل کار کند (Excel وب/موبایل). ماکروهای `.bas` فقط اختیاری‌اند.
- MUST: بعد از هر تغییر، هر دو فایل را بساز، با `soffice --headless --convert-to xlsx` دوباره محاسبه کن و صفر خطای `#...` را بررسی کن.
- NEVER: هیچ ماکرویی در ستون‌های محاسبه‌ای جدول (مثل «شماره فاکتور») ننویسد.
- شمارهٔ فاکتور = `R-` + کلید تاریخ شمسی + `-` + «فاکتور روز» (دو رقمی).

## صف کار
- تصمیم مالک (۲۰۲۶-۱۰-۲۵): صندوق وب فقط روی **یک دستگاه** کار می‌کند؛ همگام‌سازی چنددستگاهی لازم نیست.
- قاعده: `web/index.html` فقط با `python3 web/build.py` از `web/app.html` ساخته شود.
- P1: بعد از تست در OneDrive واقعی، اگر فهرست کشویی `OFFSET` مشکل داشت، فهرست ثابت جایگزین شود.
- P2: هشدار شمارهٔ تکراری: یک «فاکتور روز» برای دو مشتری متفاوت.
