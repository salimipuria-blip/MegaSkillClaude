# riha-cafe — دستورکار

```yaml
project: سامانهٔ عملیاتی کافه ریحا
type: Excel workbook generated by Python (openpyxl)
entry: build_riha_cafe_v4.py
outputs: [سامانه_کافه_ریحا_v4_آماده_شروع.xlsx, سامانه_کافه_ریحا_v4_نمونه_دمو.xlsx]
version: 4.1
check: python3 build_riha_cafe_v4.py && python3 build_riha_cafe_v4.py --clean
```

## قواعد
- MUST: فایل بدون ماکرو کامل کار کند (Excel وب/موبایل). ماکروهای `.bas` فقط اختیاری‌اند.
- MUST: بعد از هر تغییر، هر دو فایل را بساز، با `soffice --headless --convert-to xlsx` دوباره محاسبه کن و صفر خطای `#...` را بررسی کن.
- NEVER: رمز خام در مخزن نگذار. `DEFAULT_AUTH` در `web/app.html` فقط salt و هش دارد و رمزها فقط در چت به مالک داده می‌شوند.
- نسخهٔ ماکرودار: `python3 make_order_form.py`. نشانی خانه‌های فرم در سازنده و در `vba/RihaCafe_OrderForm.vba` باید یکی بماند. در قالب VBA متن فارسی فقط داخل `FA("...")` بنویس.
- NEVER: vbaProject.bin را بیرون از Excel نساز (LibreOffice فایل خراب می‌دهد). ماکرو را به‌صورت `.bas` تحویل بده.
- NEVER: هیچ ماکرویی در ستون‌های محاسبه‌ای جدول (مثل «شماره فاکتور») ننویسد.
- شمارهٔ فاکتور = `R-` + کلید تاریخ شمسی + `-` + «فاکتور روز» (دو رقمی).

## وضعیت برای جلسهٔ بعد (۲۰۲۶-۱۰-۲۶؛ مالک تا حدود ۲۰۲۶-۱۱-۰۹ محدودیت استفاده دارد)
- تحویل‌شده به مالک:
  - بستهٔ zip وب‌اپ برای Netlify Drop. نسخهٔ zip فقط ایمیل گزارش شبانه را از پیش دارد و از `web/` با جایگزینی پیش‌فرض `mailCfg` ساخته می‌شود.
  - اکسل فرم سفارش + `RihaCafe_OrderForm.bas`.
- منتظر مالک:
  - آپلود روی Netlify و تأیید ایمیل FormSubmit.
  - ایمیل صاحب کافه، برای جایگزینی گیرندهٔ گزارش.
  - وارد کردن ماکرو و تست یک سفارش در Excel واقعی. مسیر `ListObject` ماکرو هنوز در Excel تست نشده.
  - شارژ سهمیهٔ GitHub Actions.
- رمزها فقط در چت داده شده‌اند و در مخزن نیستند. اگر مالک فراموش کرد، با کد بازیابی رمز تازه بگذارد.

## صف کار
- تصمیم مالک (۲۰۲۶-۱۰-۲۵): صندوق وب فقط روی **یک دستگاه** کار می‌کند؛ همگام‌سازی چنددستگاهی لازم نیست.
- قاعده: `web/index.html` فقط با `python3 web/build.py` از `web/app.html` ساخته شود.
- NEVER: نشانی ایمیل مالک را در مخزن ننویس؛ فقط در تنظیمات برنامه یا بستهٔ آپلودی.
- P1: بعد از تست در OneDrive واقعی، اگر فهرست کشویی `OFFSET` مشکل داشت، فهرست ثابت جایگزین شود.
- P2: هشدار شمارهٔ تکراری: یک «فاکتور روز» برای دو مشتری متفاوت.
