# سامانهٔ عملیاتی کافه ریحا (اکسل)

یک فایل اکسل برای فروش و فاکتور، انبار و دستورپخت، هزینه و صندوق، حضور و حقوق، و داشبورد. تاریخ‌ها شمسی‌اند.

## فایل‌ها
| فایل | کاربرد |
|---|---|
| `سامانه_کافه_ریحا_v4_آماده_شروع.xlsx` | برای کار واقعی: فقط داده‌های پایه، بدون تراکنش |
| `سامانه_کافه_ریحا_v4_نمونه_دمو.xlsx` | نسخهٔ آزمایشی با دادهٔ نمونه |
| `build_riha_cafe_v4.py` | سازندهٔ هر دو فایل (`--clean` = نسخهٔ آماده شروع) |
| `riha_data.json`، `jalali_lib.py` | دادهٔ پایه و تبدیل تاریخ شمسی |
| `RihaCafe_Automation_v4.bas` | ماکروهای **اختیاری** برای اکسل دسکتاپ؛ برای کار فایل لازم نیستند |

## شمارهٔ فاکتور (نسخهٔ 4.1، بدون دکمه و ماکرو)
- در شیت «فروش» فقط ستون **«فاکتور روز»** را پر کنید: اولین فاکتور هر روز 1، بعدی 2 و… . همهٔ اقلام یک فاکتور همین عدد را می‌گیرند. کارت «فاکتور بعدی امروز» بالای صفحه عدد بعدی را نشان می‌دهد.
- شمارهٔ کامل، مثلاً `R-14050803-02`، با فرمول ساخته می‌شود. یکتاست و با مرتب‌کردن یا حذف ردیف‌ها تغییر نمی‌کند.
- شیت «فاکتور»: خانهٔ `I3` خالی باشد آخرین فاکتور نمایش داده می‌شود. برای فاکتورهای قبلی، شماره را از فهرست کشویی `I3` انتخاب کنید (۳۰۰ فاکتور آخر، جدیدترین اول).

## کار آنلاین
فایل را در OneDrive بگذارید و با Excel وب یا موبایل باز کنید. همهٔ فرمول‌ها آنجا کار می‌کنند و ماکرو لازم نیست. فایل به Excel 2019 به بعد یا Microsoft 365 نیاز دارد، چون از `MAXIFS` استفاده می‌کند. Google Sheets پشتیبانی نمی‌شود، چون ارجاع به جدول‌ها در آن کامل کار نمی‌کند.

## ساخت دوباره
```bash
python3 build_riha_cafe_v4.py           # نسخهٔ دمو
python3 build_riha_cafe_v4.py --clean   # نسخهٔ آماده شروع
```

## نسخهٔ وب: صندوق کافه ریحا (`web/`)
صندوق فروش آنلاین با هویت بصری منوی چاپی: ثبت سفارش از روی منو، شمارهٔ فاکتور خودکار با همان قالب اکسل (`R-yyyymmdd-NN`)، چاپ رسید ۸۰ یا ۵۸ میلی‌متری یا A5، نگه‌داشتن سفارش میز، ابطال، گزارش فروش، ویرایش منو و پرسنل، و پشتیبان JSON و خروجی CSV.
- `web/app.html`: منبع اصلی (همان فایلی که به‌صورت Artifact منتشر می‌شود).
- `web/index.html`: نسخهٔ کامل برای Vercel؛ با `python3 web/build.py` از `app.html` ساخته می‌شود. فایل `index.html` را دستی ویرایش نکنید.
- `web/fonts/`: فونت‌های Vazirmatn و Bodoni Moda روی خود سایت‌اند، تا در ایران بدون Google Fonts هم درست نمایش داده شوند.
- طراحی‌شده برای **یک دستگاه** (تصمیم مالک): داده‌ها در مرورگر همان دستگاه ذخیره می‌شوند (localStorage) و صفحه از مرورگر می‌خواهد آن‌ها را خودکار پاک نکند. هر شب پشتیبان بگیرید.
- **ورود و نقش‌ها:** دو کاربر دارد. مالک به همه‌چیز دسترسی دارد. صندوقدار فقط ثبت و چاپ سفارش، نگه‌داشتن سفارش و دیدن فاکتورهای امروز را دارد و تخفیفش سقف دارد. رمزها فقط به‌صورت هش ذخیره می‌شوند و در مخزن هیچ رمز خامی نیست. رمزهای پیش‌فرض خارج از مخزن به مالک داده شده‌اند. اگر رمز مالک فراموش شود، با کد بازیابی عوض می‌شود.
- `web/sw.js`: روی سایت اصلی، صندوق بعد از اولین باز شدن بدون اینترنت هم کار می‌کند.

### انتشار روی Vercel
1. Vercel ← Add New ← Project ← مخزن `MegaSkillClaude` را Import کنید.
2. Root Directory را `riha-cafe/web` بگذارید، Framework را `Other` و Build Command را خالی.
3. Deploy را بزنید. (اختیاری) در Settings ← Domains دامنهٔ خودتان را اضافه کنید.
