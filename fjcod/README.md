# چام | CHAM Store OS

سامانهٔ مدیریت فروشگاه چام — طراحی و توسعه: **FJCOD** · بهره‌بردار: **چام**
نسخهٔ زنده: **https://cham-store-os.vercel.app**

## مرز امنیت نسخهٔ فعلی

**این نسخه محلی است و بک‌اند/احراز هویت سروری ندارد؛ اطلاعات واقعی یا حساس وارد نکنید.**
حذف اعتماد به شناسهٔ ذخیره‌شدهٔ نشست، فقط محافظت موقت است: تغییر sessionStorage دیگر ورود
مالک نمی‌سازد، اما خود پایگاه داده و مجوزهای مرورگر هنوز قابل دستکاری‌اند. با هر بار تازه‌سازی
صفحه باید دوباره وارد شوید؛ داده‌ها پاک نمی‌شوند. migration اولیهٔ schema/RLS در مخزن برای بازبینی آماده است، اما روی دیتابیس اعمال نشده؛ انتقال واقعی Auth و داده، RPC تراکنشی فروش و تست RLS زنده هنوز انجام نشده است. مراحل لازم: [گزارش سخت‌سازی](../docs/REPO_HARDENING.md) و [طرح RLS و migration آمادهٔ بازبینی](docs/security/SUPABASE_RLS_PLAN.md).

## ورود
فقط رمز وارد می‌شود. رمز، کاربر و در نتیجه پوزیشن او را مشخص می‌کند و پنل همان پوزیشن باز می‌شود؛ به همین دلیل رمز هر کاربر یکتاست.
رمزهای اولیه (در ورود اول باید تغییر کنند):

| کاربر | پوزیشن | رمز اولیه |
|---|---|---|
| FJCOD | مالک سیستم | `fjcod1405` |
| مدیر فروشگاه | مدیر فروشگاه | `111111` |
| معاون فروشگاه | معاون فروشگاه | `222222` |
| صندوقدار ۱ / ۲ | صندوقدار | `333331` / `333332` |
| مشاور ۱ / ۲ / ۳ | مشاور فروش | `444441` / `444442` / `444443` |

پنج تلاش ناموفق = یک دقیقه توقف ورود.

## اجرا
```bash
npm install
npm run dev                    # http://localhost:5173
npm run check                  # تایپ‌چک + تست واحد + بیلد
npm run build && npm run e2e   # تست مرورگر سرتاسری
```
هر push روی این شاخه خودکار روی Vercel منتشر می‌شود.
