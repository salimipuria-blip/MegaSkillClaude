## وضعیت Vercel

ابزار متصل Vercel در این بررسی از `list_teams` فهرست خالی برگرداند؛ بنابراین **هیچ فهرست قابل اتکایی از پروژه‌ها، دامنه‌ها یا deploymentها قابل بازیابی نبود**. این به معنای نداشتن پروژه در حساب Vercel نیست. تا دسترسی به تیم/حساب صحیح برقرار نشود، نباید هیچ پروژه یا دامنه‌ای را حذف، جابه‌جا یا دارای انتشار سالم فرض کرد.

پس از دسترسی: تمام تیم‌ها/پروژه‌ها، Git repo و branch، root directory، دامنه‌های production و preview، آخرین deployment، متغیرهای محیطی بدون نمایش مقدار محرمانه، ترافیک و مصرف را تطبیق دهید. نسخهٔ آزمایشی ۳۰۰۰ فقط پس از تست محافظت از API و فایل‌های `skills-source/` عمومی شود.

## قواعد پاک‌سازی و ادغام

1. **مرجع واحد مدیریتی همین فهرست است؛ مرجع کد موتور فقط مخزن خصوصی اصلی است.** سایت‌های برندهای مستقل مخزن و deployment مستقل دارند تا دسترسی عمومی/خصوصی و چرخهٔ انتشار قاطی نشود.
2. فایل مشابه فقط با تطبیق هش و بررسی مسیرهای مصرف حذف شود؛ تاریخچهٔ Git مسیر بازیابی است. نسخه‌های طراحیِ متفاوت را به‌صرف نام مشابه تکراری نشمارید.
3. قبل از حذف مخزن، دامنه یا deployment، وابستگی‌ها، آدرس‌های عمومی، تاریخچهٔ تغییرات و نسخهٔ پشتیبان بررسی شوند.
4. پروژهٔ خالی و مخزن میان‌بر صرفاً «نامزد بایگانی» هستند. بایگانی مخزن و حذف پروژهٔ Vercel تا بررسی وابستگی‌ها انجام نشود.
5. تا استقرار و تست واقعی روی آیفون موفق نشده، سیستم ۳۰۰۰ مستقل از لپ‌تاپ اعلام نشود.
